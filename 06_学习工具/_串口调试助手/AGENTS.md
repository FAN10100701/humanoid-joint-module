## 本目录的性质

- 位置：`06_学习工具/_串口调试助手/`，是**主站入口页**（`06_学习工具/21_串口调试助手.html`，pageId `06-21`）背后的独立子应用。
- 目录名以 `_` 开头 → 站点自检 `一键自检.ps1` 的可索引页过滤（`-notmatch '\\_'`）会**自动豁免**本目录下所有 HTML 的
  search-index / sitemap / page-meta / 内联脚本语法检查，与 `06_学习工具/_作品/` 同一先例。
- **豁免不等于免检**：`*.js` 仍在自检的「外部 JS 语法」与「C4 localStorage 键名前缀」扫描范围内
  （扫描只排除 `_本地工具/`，不排除其他 `_` 目录）。所以：
  - 所有业务 JS 必须**外置**成独立文件（这样才被 `node --check` 覆盖），HTML 里零内联业务 JS；
  - `localStorage` 的键必须以 `humanoid-` / `site-` / `robot-` / `__t` 开头。
- 本目录的 HTML **不进** E2E 的「全站逐页 smoke」（同样因为不在 search-index 里）；为此在
  `_本地工具/e2e/e2e_test.py` 里单列了三条专项用例（`serial_shell` / `serial_pipeline` / `serial_export`），
  覆盖外壳与 14 个模块挂载、演示数据从传输到绘图的整条链路、以及配置落盘与 CSV 导出。
  纯函数层的回归仍必须靠 `_本地工具/校验串口应用.js` 的断言——**改完数据管线请务必跑校验脚本**。
  （这条「豁免导致检查盲区」已在 `AUDIT.md` A-71 登记为「有意保留 + 补偿脚本」。）

## 本目录硬规则

1. **零构建 / 零后端 / 零第三方运行时依赖**。不引入 npm、不引入 CDN 上的 JS 库（KaTeX / Three.js 这类站点既有 CDN 也不要用——
   本应用要能在完全离线的环境下跑）。需要的算法自己写（FFT、CRC16、表达式求值都是自研的，别改成引库）。
2. **保守 ES5**。`var` + `function`；禁 `let/const/箭头函数/模板字符串/class/解构/默认参数/展开运算符`。
   运行时 API 可以用 `Promise` / `Uint8Array` / `TextDecoder` / `fetch` / `requestAnimationFrame`（Web Serial 本身就要求新内核）。
3. **禁止 `eval` / `new Function`**。任何「用户可填写的表达式」都必须走 `js/expr.js` 的词法分析 + 调度场 + RPN 求值。
   这是安全边界：面板包 / 配置会被用户互相分享，一旦允许执行代码，导入配置就变成 XSS 后门。
4. **用户可见文本一律 `textContent`**，禁止 `innerHTML` 拼接来自串口、用户输入或导入 JSON 的内容。
5. **业务模块不碰 DOM**。只有 `ui.js` 可以直接操作静态节点，`views.js` 可以建面板骨架。其余模块要保持可在 Node 里加载。
6. **模块间不互相持有引用**，跨模块通信走 `core` 的事件总线。新增跨模块依赖前先想清楚是不是应该发个事件。
7. **每个模块保留 UMD 尾**（`if (typeof module !== "undefined" && module.exports) { module.exports = SL.xxx; }`），
   以便校验脚本 require 真源文件而不是抄一份副本。
8. **不写死站点自检项数**（站点级规则 10 的延伸）：本目录文档不得声称「自检 N 项全绿」，以脚本输出为准。
9. **`.ps1` / `.bat` 一律 ASCII-only**：本目录暂不需要这两个格式，但若将来新增，中文注释会炸脚本（PS 5.1 GBK 事故）。
10. **不改动站点共享数据文件**：`_assets/quiz-bank.js` / `ib-data-*.js` / `quest-data.js` / `path-data.js` / `site-sections.js`
    由站点侧统一维护，本目录只读不改。

## 与站点集成的约定（改本应用时需要同步的地方）

| 改动 | 需要同步的文件 |
|---|---|
| 新增 / 重命名本目录的文件 | 站点侧无（本目录被索引豁免）；但 `index.html` 底部的 `<script>` 外链顺序要改 |
| 新增子应用页面（本目录内的 .html） | 无需登记；**但要在站点入口页 `21_串口调试助手.html` 里补链接**，否则自检的相对链接审计会漏 |
| 依赖新的本地资源（图片/字体等） | 相应加入根 `sw.js` 的 `PRECACHE`（自检 C16 会校验存在性） |
| 站点版本号发布 | 本应用显示自带的 `UI.VERSION`（`js/ui.js`），**与站点 `S.VERSION` 不同源**——本应用是可独立拷走的基座，不要把它绑到站点版本上 |
| 入口页文案/数字 | `21_串口调试助手.html`（pageId `06-21`），已登记进 search-index / sitemap / page-meta / 学习地图 / index 卡片 / SITE_SECTIONS / 百度清单 |

## 验证流程

```bash
# 1) 纯函数与帧管线断言（必须全过，期望输出 SERIAL OK）
node _本地工具/校验串口应用.js

# 2) 站点级自检（JS 语法 + localStorage 键名 + 链接审计 + PRECACHE 存在性等）
node -e "0" ; powershell -ExecutionPolicy Bypass -File "_本地工具/一键自检.ps1"

# 3) 浏览器层（本目录不进全站 smoke，靠这三条专项用例；需先 pip install playwright）
python "_本地工具/e2e/e2e_test.py" --fast

# 4) 人工浏览器验收（自检覆盖不到本目录的 HTML）
powershell -ExecutionPolicy Bypass -File "_本地工具/启动服务器.ps1"
#    访问 http://127.0.0.1:8123/06_学习工具/_串口调试助手/index.html
#    必测：进入演示模式 → 七种图表框都能画出数据 → 发送回显进监视器 → 录制回放 → 各格式导出 → 双主题切换
```

## 手工验收清单（浏览器内，改完数据管线/解析/插件后逐项过）

- [ ] 演示模式（文本）下能自动建出 5 个通道，时域折线有波形
- [ ] 演示模式（HEX，点「解析」页「套用示例」）下能按 AA55 帧收齐 11 字节帧，三个字段值与预期一致，校验和不报警
- [ ] **改波特率 / 数据位 / 停止位 / 校验 / 流控**：配置立刻落盘，已连接时自动重开端口，刷新后下拉仍回填为改后的值
- [ ] **「HEX 发送」两个开关**（顶栏「编码与显示」组与底部发送条）勾选状态同步；底部发送内容按十六进制解析
- [ ] **「HEX 显示」与「显示时间戳」**勾选后串口监视器立即变化（HEX 显示=按字节流显示；时间戳=每行是否带时间）
- [ ] **自定义 HEX 协议无硬件验证**：配一个非 AA55 的帧结构（如帧头 `7E` + 1 字节载荷长度 + uint8 + int16 + xor8），进演示模式能解析出对应字段并画出波形
- [ ] 「解析」页切换文本/HEX 模式时残留字节被清空，不出现新旧规则拼半帧
- [ ] 「插件」页七种渲染器逐个添加都能画（仪表盘单通道、二维轨迹至少两通道）
- [ ] 面板编辑器改标题/通道/公式/量程/颜色后即时生效，刷新页面后配置仍在
- [ ] 发送框回车发送，演示模式下内容回显到监视器；HEX 模式发 `AA 55 01`
- [ ] 定时轮询启用后按间隔发送；改间隔后下一次发送即生效
- [ ] 预设绑了快捷键时，焦点不在输入框按该键能发送；填了期望回包时超时会提示
- [ ] 录制 → 停止 → 回放能重演波形 → 导出 JSON → 清空数据 → 导入 JSON 能还原
- [ ] 五种导出（解析 CSV / 原始 CSV / JSON / BIN / TXT）都能下载且 CSV 用 Excel 打开中文不乱码
- [ ] 浅色 / 深色主题下所有文字与图表刻度都可读
- [ ] 不支持 Web Serial 的浏览器访问时，顶部出现降级横幅且「连接设备」被禁用，演示模式仍可用
