移动鼠标穿过粒子群,感受反平方斥力涡旋

📜 核心源码(完整可跑,约 16 行)

// 每帧:半透明清屏(残影) → 粒子沿流场推进 → 加法混色画点
ctx.fillStyle = 'rgba(3,5,10,' + fade + ')';   // fade=1-残影长度
ctx.fillRect(0,0,W,H);
ctx.globalCompositeOperation = 'lighter';       // 加法发光
for(var i=0;i<N;i++){
  var p = P[i];
  // 极简流场:两套 sin/cos 叠加出"涡旋洋流"
  var vx = Math.sin(p.y*.008 + t*.6) + Math.cos(p.x*.006 - t*.4);
  var vy = Math.cos(p.x*.007 - t*.5) - Math.sin(p.y*.005 + t*.3);
  p.x += vx * speed * 1.6;  p.y += vy * speed * 1.6;
  // 鼠标扰动:反平方斥力
  var dx=p.x-mx, dy=p.y-my, d2=dx*dx+dy*dy;
  if(d2 < 22500){ var f=(150-Math.sqrt(d2))/150; p.x+=dx/d2*f*90; p.y+=dy/d2*f*90; }
  // 环绕边界
  if(p.x<0)p.x+=W; if(p.x>W)p.x-=W; if(p.y<0)p.y+=H; if(p.y>H)p.y-=H;
  ctx.fillStyle = p.c;                          // 每粒一个青-金色相
  ctx.fillRect(p.x, p.y, 1.6, 1.6);
}

要点:①残影 = 不清屏 + 低透明度覆盖,一行代码的电影感(本质是时间低通滤波);②lighter 混色让粒子重叠处自然过曝成白;③流场不需要 Perlin 噪声,两组不同相位的三角函数就足够"有机"。
