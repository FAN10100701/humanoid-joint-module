1 组一 · 理论入门

先检验机械传动与电机控制的基础概念:减速器三大件、减速比公式、FOC 三环、编码器与背隙。全部掌握后再进入硬件部分。

1. 谐波减速器的三大核心部件是?
💡 解析:谐波减速器三大核心部件是波发生器(椭圆形凸轮 + 柔性轴承,接电机高速输入)、柔轮(薄壁弹性金属杯,输出)与刚轮(刚性内齿圈,常固定)。波发生器转一圈,柔轮因比刚轮少 2 个齿而反向转过 2 个齿的角度,由此获得大减速比且啮合无侧隙、几乎零背隙。太阳轮/行星轮/内齿圈是行星减速器的结构;摆线轮/针齿壳属于 RV 摆线方案。思维导图 →
2. 行星减速器减速比 i 的计算公式(内齿圈齿数 Zr、太阳轮齿数 Zs)是?
💡 解析:行星减速器减速比 i = 1 + 内齿圈齿数 / 太阳轮齿数。例:太阳轮 Zs=12、内齿圈 Zr=48,则 i = 1 + 48/12 = 5。单级行星减速比通常只有 3~10,但反驱透明度极好,因此是准直驱(QDD)关节的首选——小米 CyberGear 用 3.5:1 单级行星,智元 PowerFlow 同为行星准直驱方案。原理动画 →
3. FOC 的全称与中文含义是?
💡 解析:FOC = Field-Oriented Control(磁场定向控制),也叫矢量控制。它通过对定子电流做坐标变换,解耦出励磁分量 Id 与转矩分量 Iq 独立控制,让三相交流电机获得类似直流电机的优良控制特性,是人形机器人关节驱动的核心算法。思维导图 →
4. FOC 三环控制从内到外的顺序是?
💡 解析:三环从内到外依次是电流环(最内、带宽最高) → 速度环(中间) → 位置环(最外)。典型采样频率:电流环 10~40kHz,速度环 1~5kHz,位置环 1kHz 左右。电流环是 FOC 的核心,决定力矩响应速度;位置环在最外,输出期望速度给速度环。思维导图 →
5. 电机端编码器在 FOC 控制中的核心作用是?
💡 解析:编码器提供转子位置(电角度),FOC 靠电角度完成 Park 变换与换相,速度环则对角度微分得到转速。人形关节常用双编码器方案:电机端编码器(高速、高分辨率)负责 FOC,输出端编码器(低速)负责消除减速器传动误差、保证末端位置精度。磁编码器如 AS5047P / MT6816 是主流。思维导图 →
6. 减速器的「背隙(回差)」是指?
💡 解析:背隙(回差)指输入轴反向转动时,输出轴开始转动前的空转角,由齿侧间隙、弹性变形等引起。背隙过大会导致位置精度下降、换向冲击与抖动。谐波减速器柔轮齿始终与刚轮啮合、无齿侧间隙,因此几乎零背隙,是人形关节高精度定位的关键;行星减速器则存在一定背隙。减速器剖面图 →

2 组二 · 硬件基础

围绕 FOC 关节驱动板的电源、驱动、采样、Layout 与通信展开,检验你读原理图与 Layout 的能力。

7. 栅极驱动(Gate Driver)的主要作用是什么?
💡 解析:MCU 引脚驱动能力弱(3.3V / 数 mA),无法快速给 MOS 栅极电容充放电;栅极预驱将 PWM 放大为10~15V 强驱动信号,并集成自举、死区时间、过流保护(nFAULT)等功能。典型芯片:DRV8313(内置 MOS,入门首选)、DRV8323RS(外置 MOS + 内置电流采样放大器)、MP6539。避坑指南 →
8. 工业关节 FOC 最常用的相电流采样方案是?
💡 解析:三电阻下桥采样(每相下桥 MOS 源极串毫欧级精密电阻)精度高、成本低,是工业首选;双电阻采样次之(第三相由基尔霍夫定律计算);单电阻母线采样成本最低但需 SVPWM 扇区重构、算法复杂,不推荐新手。采样要点:采样电阻用 Kelvin 连接、运放加 1.65V 偏置、ADC 在 PWM 导通中段触发。避坑指南 →
9. 母线大电容在驱动板中的核心作用是?
💡 解析:MOS 开关瞬间 di/dt 可达数百 A/μs,母线大电容(220μF~1000μF 电解 + 100nF 陶瓷)就近为半桥提供瞬态电流、抑制电压跌落与振铃,是决定板子性能的第一要素。它必须尽量靠近 MOS 半桥放置,走线越短越好;电机制动回灌能量还需制动电阻泄放,防止母线过压炸电容。避坑指南 →
10. FOC 驱动板 PCB Layout 最重要的原则是?
💡 解析:电力电子领域「Layout = Design」。主功率环路(母线电容+ → 上桥 MOS → 相线 → 下桥 MOS → 母线电容-)面积必须最小,否则寄生电感增大、开关振铃与 EMI 急剧恶化。同时要控好栅极驱动环路与电流检测环路:采样线用 Kelvin 连接、AGND 与 PGND 单点相连、栅极电阻 Rg 紧贴 MOS 栅极焊盘。避坑指南 →
11. MCU 的 3.3V 模拟参考电源(VDDA,供 ADC)应如何处理?
💡 解析:ADC 参考电源必须干净。模拟 3.3V(VDDA)与数字 3.3V(VDD)必须通过磁珠 / 0Ω 电阻隔离,并独立去耦(10μF + 100nF),否则数字开关噪声耦合进 ADC 会导致电流采样不准——而采样不准,FOC 算法再好也跑不起来。电源链路典型为:24V → Buck 5V → LDO 3.3V。避坑指南 →
12. CAN 总线 120Ω 终端电阻的正确接法是?
💡 解析:120Ω 终端电阻用于匹配线缆阻抗、抑制信号反射,只在总线物理两端各加一个;每个节点都加会拉低总线阻抗,导致通信失败。常见收发器:TJA1050 / TJA1042 / TCAN1042。人形机器人多关节场景常用 CAN(最高 1Mbps)与 EtherCAT 实时总线。避坑指南 →

3 组三 · 软件与算法

覆盖 SimpleFOC、坐标变换、ROS2 话题模型、仿真强化学习与 sim-to-real,检验软件栈的掌握程度。

13. SimpleFOC 是什么?
💡 解析:SimpleFOC 是最适合入门 FOC 的开源库,支持 Arduino / STM32 / ESP32 等平台,文档完善、社区活跃,配套 SimpleFOC Mini / Shield 等硬件,是入门 FOC 算法与驱动开发的最佳起点。同类开源还有 ODrive(高性能伺服控制器)、VESC、小米 MotorOS 等。固件与电机控制 →
14. Clark 变换与 Park 变换在 FOC 中的作用是?
💡 解析:Clark 变换把三相 abc 电流变为两相静止 αβ 系,Park 变换再把 αβ 变为随转子旋转的 d/q 坐标系,把交流量变成直流量:Id 控制励磁(d 轴电流 = 0 控制 / MTPA),Iq 控制转矩,之后才能用 PI 控制器精确调节。最后经逆 Park、SVPWM 生成三相占空比驱动逆变桥。固件与电机控制 →
15. ROS2 中「话题(Topic)」的通信模型是?
💡 解析:话题是发布 / 订阅(Pub/Sub)异步模型,发布者与订阅者解耦,支持一对多通信,适合连续数据流(如关节状态、IMU 数据);一问一答的同步调用是「服务(Service)」;适合长任务、可取消的是「动作(Action)」;还有参数(Parameter)与节点(Node)共同构成 ROS2 六大概念。ROS2 与机器人软件栈 →
16. MuJoCo 的主要用途是?
💡 解析:MuJoCo(Multi-Joint dynamics with Contact)是开源的高性能物理仿真器,擅长多关节刚体动力学与接触仿真,被 DeepMind、宇树等广泛用于机器人运动控制研究与强化学习训练环境(如 RL 训练流水线:观察 / 动作 / 奖励 / PPO)。同类仿真器还有 Isaac Lab / Isaac Sim。仿真与强化学习 →
17. sim-to-real(仿真到现实)迁移的常用手段是?
💡 解析:域随机化是 sim-to-real 最常用手段:训练时随机化仿真中的物理参数(质量、摩擦系数、控制延迟、传感器噪声、光照等),让策略见过足够多的"域",从而在真实环境泛化。其他手段还有系统辨识、仿真数据与真实数据混合训练、课程学习等。仿真与强化学习 →
18. PPO 是?
💡 解析:PPO 是 OpenAI 提出的策略梯度强化学习算法,通过裁剪目标函数限制每次更新步长,训练稳定、超参数鲁棒,是机器人 RL 训练(Isaac Lab / MuJoCo 环境)最常用的算法之一,常配合域随机化实现 sim-to-real 迁移。仿真与强化学习 →

4 组四 · 前沿与行业

用整机参数与前沿概念检验你对行业现状的了解:自由度、减速比选型、VLA、世界模型、灵巧手与直线执行器。

19. 宇树 G1 整机自由度大致在什么范围?
💡 解析:宇树 G1 基础版为 23 自由度,EDU 版最高 43 自由度(含灵巧手),身高约 1.27m、自重约 35kg、起售价约 ¥9.9 万,是全球首个万元级量产人形机器人。对比:H1 为 19 自由度(H1-2 升级为 27);智元灵犀 X1 为 31 自由度(本页 3D 模型 27 可动)。机型全景 →
20. 谐波减速器常见的单级减速比范围是?
💡 解析:谐波减速器单级减速比常见 30:1 ~ 160:1(如 50:1、100:1),靠柔轮与刚轮差 2 个齿实现大减速比且零背隙、体积小;3:1~10:1 是行星减速器单级范围,5:1 是小米 CyberGear 等准直驱关节的典型值。人形关节多按负载分级选型:轻载(<20N·m)用小谐波,中载(20~150N·m)用标准谐波,重载(>150N·m)用 RV / 大谐波。思维导图 →
21. VLA(视觉-语言-动作模型)是指?
💡 解析:VLA = Vision-Language-Action,把视觉感知与自然语言理解直接映射为机器人动作,代表模型有 RT-2、OpenVLA、π0、Helix 等,是具身智能的主流范式之一。它与经典"感知 → 规划 → 控制"流水线的区别在于:端到端从指令直接生成动作。VLA 与世界模型 →
22. 机器人领域的「世界模型(World Model)」是指?
💡 解析:世界模型学习环境的转移动力学——理解"状态如何演化、动作导致什么后果",从而在模型内做预测、想象与规划(如 UniSim 等),是提升机器人泛化能力的前沿趋势,常与 VLA 结合使用。VLA 与世界模型 →
23. 当前主流仿人灵巧手最常见的驱动方式是?
💡 解析:主流灵巧手用微型无刷 / 空心杯电机驱动,通过腱绳或连杆把电机后置到手腕 / 前臂,减轻手部重量与惯量——如宇树 Dex3-1(三指 7 自由度、腱绳传动、重 710g)。其他路线:气动(Shadow Hand 24DOF)、液压(高力但成本高)。核心难点是小空间内"驱动 + 传动 + 触觉传感"的集成。前沿技术专题库 →
24. 行星滚柱丝杠主要用在人形机器人的什么部位?
💡 解析:行星滚柱丝杠将电机旋转运动转化为直线运动,承载力大、寿命长、刚度高,主要用于线性执行器——典型如特斯拉 Optimus 腿部直线关节;而旋转关节(肩、肘、髋等)多用谐波减速器。行业主流方案因此分两派:旋转关节谐波 + 直线关节丝杠的混合方案,以及全准直驱(QDD)方案。3D 解剖 →
