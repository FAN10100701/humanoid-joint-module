🌧️ 电磁雨柱 GLSL · fbm 噪声

灵感来自"如果降雨数据变成雨"。把关节电机的三相电流想象成三列雨柱:fbm 分形噪声沿垂直方向平流,幂函数锐化出"一柱一柱"的雨丝,底部辉光模拟地面溅射。核心只有一句话:亮度 = pow(噪声, 3)——高次幂把柔和噪声削成锐利雨丝。
📜 源码讲解:fbm 噪声如何变成雨柱(核心 20 行)
// 价值噪声 → 5 层分形叠加(fbm):高频细节 + 低频轮廓
float fbm(vec2 p){ float v=0., a=.5;
  for(int i=0;i<5;i++){ v += a*noise(p); p*=2.03; a*=.5; }
  return v; }
void main(){
  vec2 uv = gl_FragCoord.xy/uRes;
  float col = 0.;
  for(int i=0;i<3;i++){                    // 三列雨柱(对应三相电流)
    float x = uv.x*(1.+float(i)*.4) + float(i)*1.7;
    float n = fbm(vec2(x*8., uT*uSpeed*.3 - uv.y*2. + float(i)*9.));
    col += pow(n, 3.) * (1.-uv.y) * smoothstep(0.,.15,uv.y);
  }
  vec3 c = vec3(.02,.03,.05)
         + vec3(.45,.6,.9)*col*uIntensity      // 冷色主体
         + vec3(.2,.8,.9)*pow(col*uIntensity,3.)*.6; // 高光溅射
  gl_FragColor = vec4(c, 1.);
}
要点:①噪声输入的 y 分量减去 uT → 图案向下平流;②pow(n,3.) 拉开明暗对比,只有噪声峰值存活,形成"雨丝";③三层不同缩放/偏移的雨柱叠加出纵深。

🌌 光影走廊 GLSL · Raymarching + SDF

致敬"时间切片"那条光影隧道。不用任何模型:每帧从相机发射 64 条光线,用有向距离场(SDF)描述一串无穷循环的霓虹圆环,光线步进靠近表面时累积辉光(体积光)。整个世界只有一段距离函数——这就是 Raymarching 的浪漫。
📜 源码讲解:SDF 圆环 + 光线步进辉光(核心 22 行)
// 圆环 SDF:到"半径 1.4 的圆环、管径 0.06"的有向距离
float sdTorus(vec3 p, vec2 t){
  vec2 q = vec2(length(p.xz)-t.x, p.y);
  return length(q)-t.y;
}
float map(vec3 p){
  float d = 1e9;
  for(int i=0;i<4;i++){
    vec3 q = p;
    q.z += uT*uSpeed*2. + float(i)*7.2/uDensity; // 沿 z 排开并飞向相机
    q.z = mod(q.z, 7.2) - 3.6;                   // 无限循环走廊
    d = min(d, sdTorus(q, vec2(1.4,.06)));
  }
  return d;
}
void main(){
  vec3 ro = vec3(0.,0.,-3.), rd = normalize(vec3(uv,.9)); // 相机+视线
  float glow = 0.;
  for(int i=0;i<64;i++){
    vec3 p = ro + rd*t;
    float d = map(p);
    glow += .02/(1. + d*d*40.);   // 越近越亮 → 体积辉光
    t += max(d*.8, .01);          // 步进(不精确命中,只为发光)
    if(t>20.) break;
  }
  gl_FragColor = vec4(vec3(.1,.5,1.)*glow + vec3(.6,.2,1.)*glow*glow*2., 1.);
}
要点:①mod(q.z, 7.2) 把空间折叠成无限循环;②辉光不是"打光"而是累计 1/d²——距离场天然给出"多接近物体";③蓝紫双色按 glow/glow² 混合出霓虹质感。

🏔️ 极光平原 GLSL · fbm + 色域映射

三层 fbm 噪声:底层做起伏"雪山剪影",中层做流动极光带(沿 x 弯曲的亮度脊线),顶层做星空。色彩的秘诀是用亮度值在一条"青→紫→品红"渐变带上采样,而不是直接 RGB 调色——这是所有好看 shader 的共同套路。
📜 源码讲解:亮度 → 色带采样(核心 14 行)
// 极光带:水平 fbm 曲线 + 垂直衰减
float band(vec2 uv, float t){
  float ridge = fbm(vec2(uv.x*2.2, t*.35))*.6 + uv.x*.15;
  float d = uv.y - (.55 + ridge*.35);          // 距极光脊线的距离
  return exp(-abs(d)*6.) ;                     // 高斯衰减 → 柔和光带
}
vec3 ramp(float v){                            // 亮度 → 色
  vec3 c = vec3(.0,.35,.3);                    // 青
  c = mix(c, vec3(.35,.1,.55), smoothstep(.2,.7,v)); // → 紫
  c = mix(c, vec3(.9,.25,.6), smoothstep(.7,1.,v));  // → 品红
  return c;
}
void main(){
  float a = band(uv,uT)*uIntensity;
  float mountain = smoothstep(.32,.28,uv.y + fbm(uv*3.)*.05);
  vec3 c = ramp(min(a,1.))*a + vec3(.01,.02,.04);
  c = mix(c, vec3(.005,.008,.015), mountain);  // 雪山剪影盖在最上
  c += stars(uv);                              // 顶层星点
  gl_FragColor = vec4(c,1.);
}
要点:①exp(-|d|·k) 的高斯光带比线性衰减自然得多;②ramp() 三段 mix 是"色域映射"最小实现;③雪山就是一行 smoothstep 阈值——shader 里"画山"只需要一个不等式。

🦋 相位蝴蝶群 Canvas2D · 500 粒子流场

致敬蝶群时间切片:500 个发光粒子在三角函数流场里游动,拖尾用"半透明黑罩"实现(每帧不完全清屏,旧帧按 8% 衰减)——残影本质是低通滤波。粒子轨迹由一组极简流场方程驱动,鼠标移入画布会产生扰动涡旋。
📜 源码讲解:流场 + 残影(核心 16 行)
// 每帧:半透明清屏(残影) → 粒子沿流场推进 → 加法混色画点
ctx.fillStyle = 'rgba(3,5,10,' + fade + ')';   // fade=1-残影长度
ctx.fillRect(0,0,W,H);
ctx.globalCompositeOperation = 'lighter';       // 加法发光
for(var i=0;i<N;i++){
  var p = P[i];
  // 极简流场:两套 sin/cos 叠加出"涡旋洋流"
  var vx = Math.sin(p.y*.008 + t*.6) + Math.cos(p.x*.006 - t*.4);
  var vy = Math.cos(p.x*.007 - t*.5) - Math.sin(p.y*.005 + t*.3);
  p.x += vx * speed * 1.6;  p.y += vy * speed * 1.6;
  // 鼠标扰动:反平方斥力
  var dx=p.x-mx, dy=p.y-my, d2=dx*dx+dy*dy;
  if(d2 < 22500){ var f=(150-Math.sqrt(d2))/150; p.x+=dx/d2*f*90; p.y+=dy/d2*f*90; }
  // 环绕边界
  if(p.x<0)p.x+=W; if(p.x>W)p.x-=W; if(p.y<0)p.y+=H; if(p.y>H)p.y-=H;
  ctx.fillStyle = p.c;                       // 每粒一个青-金色相
  ctx.fillRect(p.x, p.y, 1.6, 1.6);
}
要点:①残影 = 不清屏 + 低透明度覆盖,一行代码的电影感;②lighter 混色让粒子重叠处自然过曝成白;③流场不需要 Perlin 噪声,两组不同相位的三角函数就够"有机"。

5 工具箱展望:img2threejs 与产品级 3D 页

本页所有效果是"手写 GLSL"路线;另一条路是资产驱动——开源项目 img2threejs(基于参考图生成 Three.js 3D 模型) 代表了"给一张参考图 → 产出可交互 three.js 场景"的工作流,类似小米汽车官网那种产品级光影展示。站内的评估结论:

  • 适合:教学 3D 动画的"初版场景搭设"(给一张减速器剖面图 → 自动产出可旋转粗模),再人工精修——能省大量建模时间;
  • 不适合:直接替代 00_3D解剖 的官方 URDF/STL 精确模型(教学要的是真实尺寸与装配关系);
  • 下一步:若工具链成熟,优先试点"驱动电路板 3D 交互讲解页"(参考图 → 板卡粗模 → 热点标注)。
