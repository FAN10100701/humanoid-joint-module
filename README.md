# 人形机器人学习站

> 从关节模组到具身智能 —— 免费开源的人形机器人学习入门网站(软件 + 硬件 + 前沿知识)
>
> 📌 最新版本 **V2.2.34**(2026-10-16):**面板头排版/交互三修 + 拖拽合并**。①**「好多按钮和字被遮挡」是真 bug**（A-122）：网格压窄到 `228px` 时面板头内容却有 `382px`，而 `.sl-panel { overflow: hidden }` 会把放不下的按钮**整块裁掉** —— 实测被切的是 `触发 / 复制测量 / ⏸ / 收起 / ✕` 五个（`flex` 只压缩可压缩项、**不会让固定宽的按钮换行**）→ 面板头与快捷条显式 `flex-wrap: wrap`，修后在 240px 面板下逐个量「有没有元素右边界超出面板」= **0 个**。②**「y+ / y- 点击后一点效果也没有」也是真的**（A-114 补）：原来只在 `change`（失焦/回车）才写配置 —— 填了数字**没回车**画面纹丝不动 → 补 `input` 实时路径，**边打字边生效**；关键细节：实时路径**刻意不走 `updatePanel`**（那条路会重建用户正在输入的 `<input>`，光标会丢、打字会断），`change` 分支仍走 `updatePanel` 负责落盘与校验。另补组标题**「手动量程」**（原来两个空框只靠 placeholder 自述）与一键**「自动」**回自动量程。③**「小的时候还有框」= 类型角标的描边**（A-120 补）：用户把它当成了「文字介绍框」→ 去掉 `border`/`padding`，只剩标题旁一行淡灰小字；字号回到比标题小一档（V2.2.33 试过同号，同号反而分不出主次），并给「标题 vs 类型」比较加**归一化**（去空白+转小写），避免标题带空格时多画一个标签。④**新增拖拽合并**（A-121）：拖到**同类面板的头部**→那一块高亮并显示「松开即合并到这块」→松手合并。两条约束写成断言：合并区**只限头部那一条**（整块当合并区会让**重排彻底失效**）；判据与一键「并同类」**共用同一个 `canMergePanels`**。⚠️ 用户报的「三个按键问题太多」指的是面板头 `⇱ ⇔ ⤓`，**V2.2.32 已收进菜单，那条不需要改代码、需要强刷**。校验 381 → **390 项**（全 PASS，exit 0），E2E 31 → **32/32**（含 105 页全站 smoke）。完整更新历史见 [CHANGELOG.md](CHANGELOG.md)。

本项目是一套**人形机器人**交互式学习系统:把关节电机、驱动器、减速器、ROS2、仿真强化学习、具身智能大模型这些复杂知识,做成可交互的 3D 模型、原理动画、浏览器实验和图文教程,零基础也能一步步看懂。

## 🚀 快速开始

- **本地浏览(推荐)**:双击 `_本地工具\启动教学页面.bat`,自动启动服务器(http://127.0.0.1:8123)并打开浏览器。3D 解剖页必须 http 访问(URDF/STL 无法在 file:// 加载,直接双击 html 会白屏)。
- **线上访问**:GitHub Pages 部署:https://FAN10100701.github.io/humanoid-joint-module/
- **部署**:双击 `_本地工具\一键部署到GitHub.bat` 提交并推送。

## 🛠️ 技术栈

- Three.js(3D 渲染)+ STL 模型(DRACO / gzip 压缩,传输体积优化约 79%)
- 纯 HTML / CSS / JS,无需构建,浏览器直接运行
- PWA 离线缓存(根目录全站 Service Worker + 3D 解剖页独立 Service Worker)
- 本地工具:PowerShell + Node.js(语法检查、数值校验、搜索索引同步)
