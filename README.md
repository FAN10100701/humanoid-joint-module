# 人形机器人学习站

> 从关节模组到具身智能 —— 免费开源的人形机器人学习入门网站(软件 + 硬件 + 前沿知识)
>
> 📌 最新版本 **V2.2.32**(2026-10-16):**时域波形两个真 bug** + 面板头收窄 + 频谱/造数真断言。①**Y 轴手动量程一直没生效**（A-116）：快捷条那两个数字输入的 `data-qk` 是小写 `ymin`/`ymax`，而面板描述符契约（`Plugins.validate`）只认**驼峰** `yMin`/`yMax`，旧代码 `ax[k] = v` 于是往 `axis` 里写了个多余的 `ymin` 键 —— **validate 看不见、也不报错**，`.axis.yMin` 永远是 `null`，量程纹丝不动。改用显式映射表 `QK_AXIS_KEY`，实测画布刻度从自动量程的 −100/0/100 变成 **−1000/−500/0/500/1000**。②**一开触发，整块时域波形连同画布一起消失**（A-117）：触发的对齐算法本身是对的（`_trigStage=7`、`_trigAt=100`、角标「已触发…」），真 bug 在绘制层 —— `draw` 里调了 `g("--sl-warn")`/`g("--sl-ok")`，而 `g` 是 `theme()` 的**局部函数**，draw 时早已出作用域 → `g is not defined` 抛异常 → `views.redraw` 的 catch 把面板换成「该图框渲染出错，已停止刷新」并 `destroy()` 掉画布；**症状极具误导性，看着就像「触发把图弄没了」**。顺带修掉 **Shift 游标**里同一条死代码（`g("--sl-accent")` —— 令牌真名是 `--sl-accent-ink`，`--sl-accent` 根本不存在，所以「按住 Shift 点两下放游标」此前一直是坏的）。同一个坑已**第三次复发**（A-112/A-113/A-117），这次加了**不靠行号的静态闸门**：切出 `theme()` 函数体挖掉，再在剥掉注释的剩码里搜 `g("--`，残留即红。③面板头 `⇱/⇔/⤓` 收进「⋯」（CSS 收放不删元素、委托到宿主只绑一次）。④E2E 新增**可参数化造数助手**（正弦/方波/噪声/双音 × 任意通道 × 任意点数，经真管线入仓）与**独立 DFT 交叉验证**（期望值不调应用任何代码，同 bin <1dB，整 bin 下幅值精确复原 100.0/40.0）。⑤新增「**合并同类项**」（A-119）：多块图表框全叫「时域波形」时分不出哪块是哪块，工具条「并同类」+ 命令面板一键收拢 —— 保留第一块、其余移除（不搬 DOM，搬了会把 canvas 重置成 0×0）；同类 = **同类型 + 同标题**（手动改过标题的如「电流环」有意区分，不合并）；**显示设置不一致就跳过并如实报告**，不静默丢配置。校验 360 → **376 项**，E2E 27 → **31/31**（含 105 页全站 smoke）。完整更新历史见 [CHANGELOG.md](CHANGELOG.md)。

本项目是一套**人形机器人**交互式学习系统:把关节电机、驱动器、减速器、ROS2、仿真强化学习、具身智能大模型这些复杂知识,做成可交互的 3D 模型、原理动画、浏览器实验和图文教程,零基础也能一步步看懂。

## 🚀 快速开始

- **本地浏览(推荐)**:双击 `_本地工具\启动教学页面.bat`,自动启动服务器(http://127.0.0.1:8123)并打开浏览器。3D 解剖页必须 http 访问(URDF/STL 无法在 file:// 加载,直接双击 html 会白屏)。
- **线上访问**:GitHub Pages 部署:https://FAN10100701.github.io/humanoid-joint-module/
- **部署**:双击 `_本地工具\一键部署到GitHub.bat` 提交并推送。

## 🛠️ 技术栈

- Three.js(3D 渲染)+ STL 模型(DRACO / gzip 压缩,传输体积优化约 79%)
- 纯 HTML / CSS / JS,无需构建,浏览器直接运行
- PWA 离线缓存(根目录全站 Service Worker + 3D 解剖页独立 Service Worker)
- 本地工具:PowerShell + Node.js(语法检查、数值校验、搜索索引同步)
