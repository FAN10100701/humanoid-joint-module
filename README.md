# 人形机器人学习站

> 从关节模组到具身智能 —— 免费开源的人形机器人学习入门网站(软件 + 硬件 + 前沿知识)

本项目是一套**人形机器人**交互式学习系统:把关节电机、驱动器、减速器、ROS2、仿真强化学习、具身智能大模型这些复杂知识,做成可交互的 3D 模型、原理动画、浏览器实验和图文教程,零基础也能一步步看懂。

## ✨ 功能特色

- 🦾 **3D 解剖式知识可视化**:宇树 H1 / G1、智元 X1 官方模型,3D 交互拆解、关节动画、三机同屏对比、力控仿真(Three.js,DRACO 压缩提速 79%,PWA 离线可用)
- ⚙️ **三种减速器剖析**:谐波 / 行星 / 摆线 RV 剖面图、爆炸拆解、减速比公式一图看懂
- ⚡ **核心原理动画**:FOC 磁场定向、三环级联控制、ADRC 可视化
- 🛠️ **项目实操**:Hdrive 融合方案指南、立创 EDA 逐模块绘制、电源管理功率链路分析(3 个电源 Bug 复盘)
- 💻 **软件与算法**:软件学习路线图、SimpleFOC / ODrive 固件、ROS2 软件栈、MuJoCo / Isaac 仿真强化学习、VLA 与具身智能
- 🔬 **前沿知识库**:全球 15 款人形机器人机型全景、7 大前沿技术专题、论文 / 数据集 / 开源社区导航
- 🧪 **代码实验室**:浏览器内零安装实验 —— PID 整定模拟器、FOC 电流矢量可视化、倒立摆平衡控制
- 📖 **学习工具**:104 术语词典、22 问 FAQ、24 题自测、全站搜索(Ctrl+K)与学习进度打卡

## 🚀 快速开始

- **本地浏览(推荐)**:双击 `_本地工具\启动教学页面.bat`,自动启动服务器(http://127.0.0.1:8123)并打开浏览器。3D 解剖页必须 http 访问(URDF/STL 无法在 file:// 加载,直接双击 html 会白屏)。
- **线上访问**:GitHub Pages 部署:https://FAN10100701.github.io/humanoid-joint-module/
- **部署**:双击 `_本地工具\一键部署到GitHub.bat` 提交并推送。

## 🛠️ 技术栈

- Three.js(3D 渲染)+ STL 模型(DRACO / gzip 压缩,传输体积优化约 79%)
- 纯 HTML / CSS / JS,无需构建,浏览器直接运行
- PWA 离线缓存(3D 解剖页 Service Worker)
- 本地工具:PowerShell + Node.js(语法检查、数值校验、搜索索引同步)
