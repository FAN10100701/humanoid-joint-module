# 评论区接入指南(Twikoo CloudBase 云接入 · 2026-08-17 最终版)

> 背景:Twikoo 已部署到 CloudBase(云函数 + HTTP 网关 `/twikoo`),前端版本 1.7.19 与云函数一致。
> **关键结论(实测+文档核实)**:CloudBase 免费版无法添加「Web 安全域名」,跨域校验开启时会拦截 cyco.top;
> 关闭跨域校验后网关**不再自动加 CORS 头**,需要**修改云函数代码自己返回 CORS 头**——这是唯一可行的免费方案。

---

## 一、前端配置(已完成)

`_assets/giscus-config.js`:
```js
window.COMMENTS_CONFIG = {
  provider: "twikoo",
  envId: "https://twikoo-env-d1gjabi5l2e5613b2-1384309057.ap-shanghai.app.tcloudbase.com/twikoo",
  region: "",
  path: null
};
```
- **必须用完整 URL 模式**(HTTP 网关直连)。⚠ 不要改成短 ID + region:
  那会让 Twikoo 前端走腾讯云 SDK 通道,触发 `anonymousAuthProvider is not a function`
  (免费版未启用匿名登录),评论区整块不渲染。
- 前端已做:npmmirror → zstatic(国内)→ jsdelivr 多 CDN 回退 + 8s 超时跳源;调试探针输出到评论区顶部。

## 二、CloudBase 控制台操作(用户需执行)

### 步骤 1:关闭跨域校验
1. 控制台 → 云函数 → `twikoo` → **HTTP 触发器 / 云接入**
2. 找到「跨域校验」开关 → **关闭**(免费版无法加 Web 安全域名白名单,开启必拦)

### 步骤 2:云函数代码加 CORS 头(关键!)
关闭跨域校验后,网关直接转发,**不自动加 `Access-Control-Allow-Origin`**,
浏览器仍会拦截响应。需在云函数 `index.js` 的入口统一补 CORS 头:

**在 `index.js` 顶部(require 之后)加入:**
```js
// ===== CORS 补丁(2026-08-17):关闭网关跨域校验后,由云函数自行返回 CORS 头 =====
const CORS_HEADERS = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Methods': 'GET,POST,OPTIONS',
  'Access-Control-Allow-Headers': 'Content-Type, X-Requested-With'
};
const _origMain = exports.main;
exports.main = async (event, context) => {
  // OPTIONS 预检直接放行
  if (event.httpMethod === 'OPTIONS' || event.method === 'OPTIONS') {
    return { statusCode: 204, headers: CORS_HEADERS, body: '' };
  }
  const data = await _origMain(event, context);
  // 给 JSON 响应附加 CORS 头(CloudBase 网关透传 headers 字段)
  return {
    statusCode: 200,
    headers: CORS_HEADERS,
    body: typeof data === 'string' ? data : JSON.stringify(data)
  };
};
```
3. 保存并**重新部署**云函数

> 若你的云函数入口不是 `exports.main`(如 `index.main`),把 `_origMain` 换成原入口函数即可。

### 步骤 3:验证
1. 任意内容页 Ctrl+F5 强刷,评论区顶部 🔍 日志应显示:
   `配置读取 ✓ → 尝试 CDN #0/#1 → twikoo 脚本加载 ✓ → twikoo.init 调用 ✓`
2. 发一条测试评论;「⚙️ 管理」设置管理员密码
   - 完整 URL 模式走**非腾讯云管理流程**:直接小齿轮设密码即可,**不需要私钥**
   - 私钥(自定义登录私钥)仅在腾讯云 SDK 模式(短 ID)下需要,本方案用不到

## 三、常见问题

- **`anonymousAuthProvider is not a function`**:前端用了短 ID + region 模式 → 改回完整 URL(见第一节)
- **评论失败 0 且评论区不渲染**:CDN 全部不可达(探针会显示)→ 检查网络;或 init 失败(看探针最后一行)
- **评论失败 0 但评论区渲染了**:网关 CORS 未放行 → 执行第二节步骤 1+2
- **评论区只有部分页面显示**:sw 缓存了旧版 site.js,强刷(Ctrl+F5)即可;所有 `.container` 页面都有评论区
- **换 Valine(备用)**:LeanCloud 国内版纯配置零部署,不存在 CORS 问题;把 provider 改 "valine" 并填 appId/appKey
