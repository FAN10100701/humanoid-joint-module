# 评论区接入指南(Valine / Twikoo 双方案 · 2026-08-17)

> 背景:Giscus 后端 giscus.app 在国内被墙 → 已切换前端体系(site.js `mountComments` 支持两种 provider)。
> 现状:**Twikoo 需要自托管后端**(CloudBase 没有现成扩展,需手动部署云函数),若想最快跑通,用 **Valine**(LeanCloud 国内版,纯配置零部署,约 5 分钟)。
> 切换方式:只改 `_assets/giscus-config.js` 一个文件,无需动任何页面。

---

## 方案 A:Valine + LeanCloud 国内版(推荐 · 零部署)

Valine 是纯前端评论系统,数据存 LeanCloud;国内版免费、实名后即可用,无需服务器/云函数。

### 一、注册 LeanCloud 国内版

1. 打开 https://console.leancloud.cn → 微信扫码注册(个人即可)
2. 创建应用(开发版免费):「创建应用」→ 名称随意(如 `humanoid-comments`)→ 选择**华东/华北节点**均可
3. 进入应用 → 左侧「**设置 → 应用凭证**」,记下两项:
   - **AppID**(形如 `xxxxx-xxxxxxxxxxxx`)
   - **AppKey**(形如 `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`)

### 二、填入配置

用编辑器打开 `_assets/giscus-config.js`,改为:

```js
window.COMMENTS_CONFIG = {
  provider: "valine",
  appId: "你的AppID",
  appKey: "你的AppKey",
  serverURLs: null,  /* 国内版留 null;国际版填 https://xxx.api.lncldglobal.com */
  envId: null,
  region: ""
};
```

### 三、部署与验证

1. 推送 GitHub,等 1-3 分钟(或本地直接双击打开 html 也能测)
2. 打开任意内容页(如 `https://cyco.top/06_软件与算法/09_ROS2入门实战_第一个节点.html`),Ctrl+F5 强刷
3. 滚到底部:「💬 讨论与反馈」出现评论框(昵称+邮箱+内容,无需登录;邮箱是 Gravatar 头像用,不会公开)
4. 发一条测试评论;管理:LeanCloud 控制台 → 你的应用 →「**数据存储 → 结构化数据**」→ 表 `Comment` 里可删改

### 四、Valine 常见问题

- **评论不出现**:①appId/appKey 填错或留 null(留 null 时整个评论区不显示,属正常)②LeanCloud 实名未通过(新账号需在控制台完成实名,否则请求 403)③浏览器缓存,强刷
- **评论发不出去**:检查 LeanCloud 控制台 → 设置 → 安全设置里「**数据存储权限**」是否允许匿名读写;教学站建议勾选「允许匿名用户创建记录」
- **表情/头像**:Valine 内置表情包与 Gravatar 头像,开箱即用

## 方案 B:Twikoo + 自托管后端(功能更强,但要部署)

Twikoo 功能多(点赞/置顶/管理后台),但**必须有一个后端**。CloudBase 没有官方扩展,需要手动部署云函数,或改用第三方平台:

### 方式 1:Zeabur(最省事,约 10 分钟,免费额度)

1. 打开 https://zeabur.com → GitHub 登录(需能访问外网;国内访问不稳定时可挂代理或换方式 2)
2. 新建项目 → 选择模板 **Twikoo**(官方模板)→ 部署
3. 部署完成后会得到一个访问地址(形如 `https://xxx.zeabur.app`),这个 URL 就是 envId

### 方式 2:Vercel(免费,国内访问速度一般)

1. 打开 https://vercel.com → GitHub 登录
2. 「New Project」→ 导入仓库 `imaegoo/twikoo`(或 fork 后导入)→ Deploy
3. 得到 `https://xxx.vercel.app`,即 envId;国内直连可能慢,可考虑接自己的域名

### 方式 3:CloudBase 手动部署云函数(官方文档流程)

CloudBase 控制台 →「云函数」→ 新建云函数 → 运行时 Node.js → 代码粘贴 Twikoo 官方云函数版(`https://github.com/twikoojs/twikoo-cloudbase` 里的 `functions` 目录)→ 创建触发器(云接入)得到 `https://xxx.tcb.qcloud.la/twikoo/`。流程较长,文档:https://twikoo.js.org/backend.html#cloudbase

### 填入配置

```js
window.COMMENTS_CONFIG = {
  provider: "twikoo",
  envId: "你的后端地址",   /* Zeabur/Vercel 的 https 地址,或 CloudBase 云接入地址 */
  region: "",              /* 海外节点按需填 ap-shanghai 等 */
  appId: null, appKey: null, serverURLs: null
};
```

### 验证

同方案 A 第三步;Twikoo 的管理后台在评论框内(管理员密码登录)或后端控制台。

---

## 三、通用说明

- **切换 provider**:只改 `_assets/giscus-config.js`,刷新即生效,页面无需任何改动
- **不想显示评论区**:把 `provider` 保留但 appId/envId 留 `null` 即可(全站隐藏)
- **CDN 回退**:Valine/Twikoo 前端脚本都做了 jsDelivr → npmmirror 多 CDN 回退,国内单线路故障不影响
- **样式适配**:评论框挂在每页 `💬 讨论与反馈` 区块,已适配深浅主题;想微调告诉我
