# 评论区接入指南(Twikoo · 2026-08-17)

> 背景:Giscus 的后端 giscus.app 在国内被墙,评论区无法工作,已切换为 **Twikoo**——
> 前端 jsDelivr(国内可达),后端用腾讯云 CloudBase 免费版。约 10 分钟可完成。

## 一、注册腾讯云 CloudBase(免费)

1. 打开 https://cloud.tencent.com/product/tcb → 点「立即使用」,用微信扫码登录(个人即可,无需企业认证)
2. 进入控制台 → 「环境」→「新建环境」
   - 环境名称随意,如 `humanoid-comments`
   - **计费方式选「包年包月 - 免费版」**(每月有免费额度,评论量小完全够用;若提示需付费,检查是否选错套餐,免费版存在)
3. 等待环境创建完成(约 1 分钟),记下**环境 ID**(形如 `humanoid-comments-1a2b3c`)

## 二、安装 Twikoo 扩展

1. 在环境内左侧找到「**扩展能力**」(或「扩展应用」)
2. 搜索 **Twikoo**,点「安装」
3. 按引导完成安装(可能需要设置管理员密码,记下来)
4. 安装完成后,Twikoo 扩展会给一个**访问地址**(形如 `https://xxx.tcb.qcloud.la/twikoo/`),同时你的环境 ID 就是 envId

## 三、填入配置

1. 用编辑器打开 `_assets/giscus-config.js`(文件名保留,内容已是 Twikoo 配置)
2. 把 `envId: null` 改为你的环境 ID:
   ```js
   window.COMMENTS_CONFIG = { provider:"twikoo", envId:"humanoid-comments-1a2b3c", region:"" };
   ```
3. 部署(推送到 GitHub,等 1-3 分钟)

## 四、验证

1. 打开任意内容页(如 `https://cyco.top/06_软件与算法/09_ROS2入门实战_第一个节点.html`),Ctrl+F5 强刷
2. 滚动到底部:「💬 讨论与反馈」下出现 Twikoo 评论框(可昵称+邮箱+内容评论,无需登录)
3. 发一条测试评论;管理后台(CloudBase 控制台 → Twikoo 扩展)可管理/删除评论

## 五、常见问题

- **评论区不出现**:①envId 没填/填错(填 null 时不显示,属正常)②jsDelivr 在你的网络不可达(极少)③浏览器缓存,强刷
- **想改评论样式/开关**:Twikoo 支持前端参数(如 dark 主题适配),需要时告诉我
- **免费额度**:CloudBase 免费版对个人教学站评论量绰绰有余;若未来流量大涨,可升级或换自托管(Twikoo 支持 Vercel/自建服务器)
