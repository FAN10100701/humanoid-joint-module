说明「下载门控」是什么，以及如何把最精细的开源 SolidWorks 模型下载进项目，由助手完成整合。

一、什么是「下载门控」？

「下载门控」是指：网站为了防自动下载/防刷量，在下载链接前加了一道「真人验证」——你必须用真实浏览器打开页面、手动点一下「Download」按钮，服务器才会返回文件。它用 JavaScript + 一次性令牌校验来访者，脚本和命令行工具无法取到文件（助手尝试时被服务器拒绝，提示"You are not allowed to download"）。

对你是免费的：只需在浏览器里点几下，就能正常下载。也就是说，这一步需要你手动完成，之后交给助手整合即可。

来自 howtomechatronics.com（Dejan 的知名开源教程网站），提供官方级参数化建模的谐波减速器和摆线减速器，比例准确、可拆解零件清晰，正好替换网页里现有重合错乱的自建模型。

三、下载步骤

1
用 Chrome / Edge 打开上面任一链接（建议先谐波，再摆线，一次一个）。
2
页面中找到 Download 按钮，点击后会弹出「解锁/验证」提示，按提示操作即可（通常直接就是下载按钮）。
3
下载到的是一个 .rar 压缩包（谐波 1.04MB / 摆线 3.36MB）。
4
解压后用 WinRAR / 7-Zip 解压，得到里面一个个独立的 .STL 零件文件。

四、放到项目哪些位置？

解压后，请把 STL 文件分别放到下面两个文件夹（保持文件名，不要改名）：

谐波减速器 → 放入：
人形机器人关节模组\00_3D解剖\models\harmonic_htm\

摆线减速器 → 放入：
人形机器人关节模组\00_3D解剖\models\cycloidal_htm\

（文件夹不存在就新建这两个文件夹。放好后告诉助手「已放好」，助手统一点击零件让他们在网页里正确装配。）

五、放好后，助手会做什么

  1. 读取每个 STL 的真实尺寸，统一按真实比例缩放（避免现在的「独立缩放+假堆叠」导致的重合错乱）。
  2. 把零件厚度方向对齐到 Y 轴，与现有谐波场景一致。
  3. 更新 buildTdHarmonic / buildTdCycloidal 里的零件引用与装配位姿，让拆解动画正确、不重叠。
  4. 同步更新网页里的零件说明文字与参数表。
  5. 用本地服务器验证页面能正常加载，且不影响现有的关节模组、行星减速器等其它场景。
提示：行星减速器已用 CyberGear 开源行星齿轮箱（可在 GitHub 直接下载、无需手动）完成替换，本次教程只针对被门控的谐波和摆线两个文件。
