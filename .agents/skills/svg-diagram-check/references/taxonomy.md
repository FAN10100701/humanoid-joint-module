# 问题分类学与修法(按历史事故沉淀)

> 每类问题给出:静态信号(哪个检查项抓到)/ 目检信号(截图上长什么样)/ 钦定修法(带代码)。严重级:P1 不可读或结构损坏 > P2 溢出重叠 > P3 一致性。

## P1-1 悬空浅色字(历史 365 处,最大事故)

- **静态信号**:审计脚本 `[E] 浅色字`——fill 为硬编码 hex、亮度 >0.62、灰性(max(rgb)-min(rgb)<40)、无 class、且不在深底白名单。
- **目检信号**:浅色主题下浅灰/浅蓝字几乎看不见;深色主题下正常——"只在深色下好看"就是它。
- **钦定修法**(按优先级):
  1. 中性注释文字 → 改 `#64748b`(双向可读,一处改动两主题通吃);
  2. 有语义颜色诉求(红/绿/橙系)→ 改 `.my-*` 双主题类对(浅色深字 + 深色浅字),复用现有类,没有就成对新增;
  3. 确在深底图卡内 → 保留浅字,不改(脚本白名单自动放行)。
- **反面案例**:`#8b98a9/#9aa4b2` 直接用在无图卡包裹的 SVG 里——这就是当初 365 处的来源。

## P1-2 marker 悬空引用 / id 重复(结构损坏)

- **静态信号**:`[E] marker 引用不存在` / `[E] marker id 重复`。
- **目检信号**:线末端无箭头(裸线);或同一页部分图的箭头消失(id 重复时后定义者胜,前面的图箭头丢失)。
- **修法**:补定义 `<marker id="…">`(按 rules.md §5 钦定写法);重复 id 改名并同步 `url(#…)` 引用。

## P1-3 SVG 结构损坏

- **静态信号**:`[E] <svg> 未配平` / `[E] 缺 viewBox`。
- **目检信号**:整图不渲染 / 渲染成默认 300×150 被截断。
- **修法**:配平标签;补 `viewBox="0 0 W H"`(图幅按 rules.md §1)。

## P2-1 文字溢出(历史 16 处)

- **静态信号**:`[E] 溢出`——按「汉字数×字号 + 西文数×0.55×字号」估算宽,`text-anchor` 换算后超出 viewBox 边界 2px(仅查自带 font-size 且 ≥9 的非旋转 text)。
- **目检信号**:文字顶到图边/被裁掉半个字;中文标签后半截出画。
- **修法**(优先级递减):缩短文案(如「下一拍窗口」→「下拍窗口」) > `<tspan x="…" dy="1.4em">` 拆行(第二行记得同步改 text-anchor 与 x) > 拉宽 viewBox(最后手段,牵动整图布局) > 拆成两张图。
- **注意**:深底卡内的溢出同样要修,脚本会标注「(深底卡)」。

## P2-2 标签重叠(历史 14 处,只能目检)

- **静态信号**:`[W] 疑似重叠`——两个独立 `<text>` 估算包围盒相交面积 > 35%。**静态只做筛查,真伪以截图为准**(既有真问题也有误报,如双色标题刻意叠印)。
- **历史案例**:Roofline 带「受限」标签压带色块、MPC「下一拍」窗口标签压坐标轴、EKF「延迟补偿」标签压曲线、SVPWM 零矢量标签压扇区线、FSM done_set/start 标签互叠;2026-09-05 新增实锤:GRPO 组采样图中绿「优势=+正→强化」与红「优势=负→抑制」两标签同 y 行起点仅差 100px,压盖 82px——静态报警与截图目检双重确认后按"移位错开"修复。
- **修法**(优先级递减):沿空闲方向移位错开(同 y 行的两个标签,后者 x ≥ 前者 x + 前者估算宽 + 16px)> 加引出线(`line` + 端点小圆点) > y 向分层错行 > 缩短标签。
- **修完必须复截两主题**:移位后常在另一主题下压到别的元素。

## P2-3 公式撑破图卡

- **静态信号**:无(脚本不查 KaTeX 宽度)。
- **目检信号**:公式横向溢出 `.formula` 块或图卡;KaTeX 报错红字。
- **修法**:长公式拆两条(等号断开),或用 `\begin{aligned}` 分行;改后确认页面公式走 site.js 统一 KaTeX 加载器。

## P3-1 缺图注

- **静态信号**:`[W] 缺图注`——SVG 结束后 300 字符内无 `my-fig-cap`/`cap` 类/`<figcaption>`。
- **修法**:补 `<div class="my-fig-cap">图N ××</div>`,编号接续全页顺序。

## P3-2 字号过小

- **静态信号**:`[W] 字号过小`(font-size < 8.5)。
- **裁决**:轴刻度、单位等辅助信息 8.5px 可接受(不报警);低于 8.5 的正文性文字提到 ≥9.5。

## P3-3 缺 aria / 根缺 font-family

- **静态信号**:`[W] 缺 role/aria-label`、`[W] 根缺 font-family`。
- **修法**:根上补 `role="img" aria-label="××流程图"` 与 `font-family="Microsoft YaHei,sans-serif"`。

## P3-4 元素越界

- **静态信号**:`[W] 元素越界`——rect/circle 超出 viewBox ±2px。
- **裁决**:刻意出血(背景色带)可接受;内容性元素收回来。

## 修复循环纪律

1. 每轮只修"已确认"的问题,修完立即重跑脚本/重截,不攒批。
2. 浅色字修复优先 `#64748b`,一处一改,不要顺手重构无关代码。
3. 深底白名单内的浅字**不许改深**,那是合法设计。
4. 单页 5 轮修不完 → 停止微调,重新规划该图布局(坐标分组、盒宽、行距)。
5. 批量 ≥10 处 → 修复摘要入 `docs/审计/`,跑板块评分与一键自检收口。
