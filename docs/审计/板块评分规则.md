# 板块评分规则(V1.1 · 2026-09-06 · V2.1.21 板块编号连续化适配)

> 对全站 9 个板块做**四维量化评分**,与逐页的《知识点评估报告》互补:那边回答"每页好不好",这里回答"每个板块强在哪、弱在哪、下一步修什么"。
> 全部指标由 `_本地工具/板块评分.js` 自动计算(`node _本地工具/板块评分.js`),本文档是脚本的计分依据,两者必须同步改。

## 一、适用范围与总分构成

- **参评板块**(9 个,与 `_assets/site-sections.js` 对应,V2.1.21 起连续编号):00 3D解剖可视化 / 01 理论入门 / 02 硬件基础 / 03 项目实操 / 04 软件算法与升级进阶(含原 04 升级进阶 3 页,现 04-23~25) / 05 前沿知识库 / 06 学习工具 / 07 大模型与具身智能 / 08 NPU与数字IC设计。
- **不参评**:03_项目实操/13_HdriveV2工程(工程目录镜像)、首页、404。
- **归组方式**:按页面所在目录归组(非 pageId 前缀),因此 00 板块含未注册 pageId 的解剖主可视化页。
- **总分 100** = 学习内容 30 + 学习效果 25 + 知识点掌握 25 + 图片准确率 20。

**档位**:A ≥ 85(可直接作为对外展示样板)| B 70–84(达标,按建议修补)| C 55–69(存在明显短板)| D < 55(需要专项整修)。

## 二、维度一:学习内容(30 分)——"这页教得全不全"

按**页均**计分(板块内每页先得分子项,再取平均):

| 子项 | 分值 | 计分规则 |
|---|---|---|
| 正文篇幅 | 6 | 页面可见文本字数(去 script/style/svg):≥5000 字→6;≥3000→5;≥2000→4;≥1200→3;≥600→2;其余→1 |
| 结构密度 | 6 | h2 章节数:≥6→3,≥4→2,≥2→1;h3 知识点数:≥6→3,≥3→2,≥1→1 |
| 学习目标 | 2 | 有 key-point 学习目标块→2,无→0 |
| 组件多样性 | 8 | 表格 ≥1→2;代码块 `<pre>` ≥1→2;提示框(box-tip/box-warn)≥1→2;步骤流/折叠面板(step-flow/details)≥1→2 |
| 公式与误区 | 4 | KaTeX 公式 ≥3→2、≥1→1;"误区/易错/避坑/调试"内容命中→2 |
| 参考资料 | 4 | 有资源卡组(box-tip/表格含外链 ≥3 条)→4;有少量外链→2;无→0 |

**板块适配**:06 学习工具的"公式与误区"与"参考资料"两项(共 8 分)替换为"交互功能组件"(button/input/canvas/select ≥3 类→8、2 类→5、1 类→2);00 3D 页篇幅与结构阈值减半(交互实验室以功能密度代替文本密度)。

## 三、维度二:学习效果(25 分)——"学完能不能练、能不能留存"

| 子项 | 分值 | 计分规则 |
|---|---|---|
| 页均自测题 | 10 | 每页自测题数:≥4→8,≥2→5,≥1→3,0→0;加解析质量:quiz 解析均长 ≥120 字→+2 |
| 注册完整度 | 5 | 板块内页面 pageId 同时登记于 SITE_SECTIONS + page-meta + search-index 的占比 ×5 |
| 学习路径引用率 | 4 | 板块页面 id 被 path-data 任一路径引用的占比 ×4 |
| 搜索可发现性 | 3 | 页均:search-index 条目含 ≥4 个关键词或拼音/别名→3,有条目→1.5,无→0 |
| 练习联动 | 3 | 板块页面被 quiz-bank / 闯关自建题(q:xxx 的 link)指向的页面占比 ×3 |

## 四、维度三:知识点掌握(25 分)——"学的东西题库里考不考"

| 子项 | 分值 | 计分规则 |
|---|---|---|
| 题库指向覆盖 | 10 | 板块页面被保研题库(ib-data 题目 links 或学科 rel)指向的**页面占比** ×10 |
| 题目数量充足 | 8 | 指向该板块的 ib 题目数 vs 板块页面数:≥1.0×→8;≥0.6×→6;≥3 题→4;≥1 题→2;0 题→0 |
| 闯关覆盖 | 4 | 板块页面被闯关题目(ref: 条目的 links 或 q: 自建题 link)指向→4;仅页内自测题→2;全无→0 |
| 追问深度 | 3 | 与该板块相关 ib 题目的 follow 平均条数:≥2→3;≥1→2;有题目但无追问→1;无题目→0 |

> 设计意图:大模型/NPU/前沿板块(今 07/08/05)在 2026-09-05 前三项均为 0,是本维度的典型失分案例;补学科后应 ≥15 分。

## 五、维度四:图片准确率(20 分)——"图对不对、清不清、稳不稳"

| 子项 | 分值 | 计分规则 |
|---|---|---|
| 图注覆盖 | 5 | 板块内联 SVG 带图注(my-fig-cap 或图注文本)的占比 ×5;全板块无 SVG 页面占比 >50% 时按含图页占比折算并在报告标注"图示偏少" |
| 双主题安全 | 5 | 硬编码浅色悬空字(SVG text/tspan 的 fill 亮度 >0.62 且无 my- 主题类,排除纯白):0 处→5;1–3 处→3;>3 处→1 |
| 文字溢出风险 | 5 | SVG text 按"字数×字号"估算宽度超出 viewBox 右边界:0 处→5;1–3 处→3;>3 处→1 |
| 资产完整 | 5 | img 引用存在且 alt 完整 ×2.5 + 含 .formula 的页面走 site.js 统一 KaTeX 加载器(非页面私引 CDN)×2.5 |

> 静态规则只做**筛查**,评分结论以风险页截图目检为准(目检发现的硬伤当场修,修后复跑脚本)。

## 六、修改建议生成规则

脚本对每个**失分子项**输出一条建议,按失分从大到小取每板块 Top N:

| 触发条件 | 建议模板 |
|---|---|
| 页均自测题 <2 | 「{id 列表} 缺自测题,每页至少补 2~4 题(带逐项解析)」 |
| 注册不完整 | 「{id} 未登记:{缺哪件套},用 _本地工具/登记页面.js 补齐」 |
| path 引用率 <0.3 | 「板块{key} 几乎不在任何学习路径上,考虑加入 path-data 对应路径阶段」 |
| 题库指向覆盖 <0.5 | 「板块{key} 的 {未覆盖页列表} 无题目关联,在 ib-data 相应学科补题或补 links」 |
| 题目数量 0 | 「板块{key} 零题库覆盖,新增学科或挂靠现有学科出题」 |
| 图注覆盖 <0.8 | 「{id} 的 SVG 缺图注(my-fig-cap),读图自解释性不足」 |
| 悬空浅色字 >0 | 「{id} SVG 存在 N 处硬编码浅色字,改 .my-* 双主题类或 #64748b」 |
| 溢出风险 >0 | 「{id} SVG 有 N 处疑似文字溢出,逐图目检并缩短文案/换行」 |
| 篇幅 <1200 字 | 「{id} 正文过薄(<1200 字),按页面模板补齐章节」 |
