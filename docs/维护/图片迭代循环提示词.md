## 提示词正文(复制以下全部内容)

对本研究站(纯静态中文学习站,手写内联 SVG 流程图为图片主体)执行一轮完整的**图片问题查找与修复迭代**,使用 svg-diagram-check skill(先完整阅读该 skill 及其 references/rules.md、references/taxonomy.md 再动手)。

**本次范围**:【全站 29 个含 SVG 页面 / 06_软件与算法板块 / 指定页面】(三选一,小范围优先)

### 第一步:静态审计建立问题清单

```bash
node .agents/skills/svg-diagram-check/scripts/svg_audit.js --all
```

以**当前输出为准**建立修复台账(不要凭历史记忆)。已知基线:E=0;W 约 21 条(11 疑似重叠、6 缺 aria、4 缺图注)。每条 W 必须有裁决结果:**修**或**判误报(写明理由)**,不许留悬而未决的。

### 第二步:截图目检(所有裁决与审美检查在这里做)

- 启动服务器:`powershell -ExecutionPolicy Bypass -File "_本地工具/启动服务器.ps1"`(8123;若连接即断,改用 `node .agents/skills/svg-diagram-check/scripts/shot_server.js` 走 8199)。
- browser-use 打开页面。**改完文件必须加 `?v=N` 绕过 Service Worker 预缓存,否则看到旧图**。
- 每页截**浅色与深色两个主题**(深色:`document.documentElement.setAttribute('data-theme-early','dark')` + localStorage `site-theme='dark'`;浅色同理置 light;改完建议 reload 让站点自身初始化走对分支)。
- 重叠类 W 以截图为准裁决;截图通道超时等 3 秒重试一次,再失败就重开标签页。

### 第三步:修复(每修一处,立即复审该页 + 复截两主题)

按 taxonomy.md 对应修法执行,严守以下**网页审美约束**:

**布局与排版**
1. 对齐优先:同一行的盒、标签、图例必须基线/中线对齐;间距不得小于当前字号(拥挤的图宁可拆图)。
2. 信息层次:图名 > 节点标题 > 节点正文 > 注释,字号依次递减且全站一致(标题 12~14、正文 10~12、注释下限 8.5);不许出现同级不同字号的图。
3. 文字与图形零压盖:标签不穿线、不压色块边界;同 y 行多标签,后者 x ≥ 前者 x + 估算宽 + 16px。
4. 密度控制:单图节点 ≤ 9 个,超出拆分主图+子图;留白率不低于 20%,四边留白 ≥ 8px。
5. 视觉结构即信息:线型(实线主链/虚线反馈)、颜色、编号都必须编码真实含义,删掉一切纯装饰元素;完稿前问"哪条线/哪个标签可以删",删掉它。

**颜色与可读性**
6. 语义色锁死:蓝 #58a6ff=主流程/信号,橙 #f59e0b=警示/强调,绿 #22c55e=成功,红 #ef4444=错误/禁止,中性注释一律 #64748b;同图内不混用语义。
7. 双主题底线:浅色与深色主题下每段文字对比度都必须可读;硬编码浅色 hex 是红线,需要主题区分的用 .my-* 成对类;**深底盒内的合法浅字(#9aa4b2 等)不许改成深色**(白名单自动识别,误杀比漏报更糟)。
8. marker 箭头 fill 是硬编码色,选双向可读色;线不裸收尾,回流线也要带箭头。

**一致性**
9. 图注:每图配 `my-fig-cap`(图①②…全页连续,格式「图N:标题——一句话点睛」);判"缺图注"前先目检确认图注是否真缺(可能只是距离较远未被脚本窗口扫到,勿盲修)。
10. 图幅与图卡:viewBox 宽 560~780、高 150~430;统一用 `.my-fig` 图卡包裹;同板块同类图(如都叫"架构图")布局风格一致。

### 第四步:收口验收

- 该页验收标准:svg_audit 该页 0E,W 每条有裁决;两主题 8 项目检全过(可读/文字/箭头连线/框对齐/图注/颜色语义/公式/删一个元素)。
- 单页修复循环上限 5 轮,修不完说明版式有问题,重新规划布局而非继续微调。
- 全部完成后:重跑 `node _本地工具/板块评分.js` 确认浅色字/溢出为 0、评分不回退;跑 `_本地工具/一键自检.bat` 确认 27 项全绿。
- 净修复 ≥10 处:在 docs/审计/ 写修复摘要(日期、页数、处数、手法、误报清单);发现脚本/结构性 bug 按 AUDIT.md 约定回写台账。

**纪律红线**:不动与图无关的代码;不改口径(浅色字/溢出判定与板块评分.js 两处同步);不提交 git(等我确认)。
