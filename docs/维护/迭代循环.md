# 迭代循环(LOOP)· 自优化七步流程

> 本站持续自我优化的固定流程。**对 AI 助手说「跑一轮 loop」即按本文档 S1→S7 执行一遍;对人是 10 分钟可对照的检查单。**
> 建立时间:2026-09-02(V2.1.7)。配套:`AUDIT.md` 隐患台账、`_本地工具/一键自检.ps1`(21 项)。

## 循环总览

```
S1 快检 → S2 选题 → S3 修复 → S4 验证 → S5 发版 → S6 复盘回写 → S7 提交
   ▲                                                            │
   └────────────────── 下一轮从这里继续 ◄────────────────────────┘
```

一轮原则:**小步快跑**。每轮处理 1~3 条台账条目,一轮一个发版号,修不完的留在台账里下一轮继续。禁止顺手改与选题无关的文件。

## S1 快检(2 分钟)

1. 跑 `_本地工具/一键自检.ps1`(或双击 `一键自检.bat`)。
2. **全绿** → 进 S2;**有红** → 红项本身就是本轮最高优先选题(先修红再谈别的)。
3. 可选加测:双击 `启动教学页面.bat`,打开 `08_学习工具/15_全站体检.html` 看浏览器侧审计。

## S2 选题(1 分钟)

1. 打开 `AUDIT.md`,按 `P0 > P1 > P2 > P3` 取最前面的 1~3 条 `开放` 条目。
2. 台账**没有开放条目**时,做一轮主动巡检并刷新台账,任选一个维度:
   - **性能**:大文件、首屏加载、canvas/动画、模型体积;
   - **移动端**:窄视口逐页过、触控目标、sticky-hover;
   - **数据口径**:题数/页数/关数与实际一致、过时注释;
   - **健壮性**:断网/离线/file:// 场景、CDN 挂掉场景;
   - **内容正确性**:抽查公式与数值(配 `_本地工具/校验*.js`)。
3. 巡检发现写入台账(新 ID),再从中选题。

## S3 修复(主体工作)

严格遵守既有工程纪律(详见 `CONTRIBUTING.md` 与 `docs/协作/给协作者的交接说明.md`):

- **单源纪律**:题库只改 `ib-data-*.js`/`quiz-bank.js`;板块/页面清单只改 `site-sections.js`;统计数字只改 `site.js` 的 `S.STATS`;活动打卡只用 `Site.logActivity()`。
- **登记纪律**:新增页面跑 `_本地工具/登记页面.js` 六处登记;新增 `_assets/*.js` 记得登记进根 `sw.js` 的 PRECACHE 清单。
- **兼容纪律**:站点代码保守 ES5;`_本地工具/*.ps1` 必须 ASCII-only(PS 5.1 把无 BOM UTF-8 读成 GBK)。
- **史实纪律**:首页 `#version` 历史条目与 `CHANGELOG.md` 旧条目里的数字/表述是史实,不改。
- **修法偏好**:先修根因(单源化、动态化),再考虑补丁;每处修改留一行 `V2.1.x:` 注释说明动机。

## S4 验证(改了什么测什么)

1. `_本地工具/一键自检.ps1` 全绿(21 项:8 类基础 + C1~C5 防回归)。
2. 涉及页面打开 `?selftest=1` 看自检挂件全 ✅。
3. 改了数学/动画逻辑:跑对应 `_本地工具/校验*.js`(期望 MATH OK / ANIM OK)。
4. 浏览器实测(127.0.0.1:8123):正常路径 + 一个异常场景(断网刷新 / 直开 file:// / 窄视口)。

## S5 发版

1. 跑 `_本地工具/发版.ps1`,输入新版本号(自动同步 site.js / index 两处 / footer / sw.js CACHE 五处)。
2. `CHANGELOG.md` **顶部**插入本条:格式照旧 `## V2.1.x · 日期 · 标题` + emoji 要点。
3. 首页 `index.html` 的 `#version` 区块**同步登记同一条内容**(双登记纪律)。
4. 若新增了 `_assets` 文件:确认已进 `sw.js` PRECACHE。

## S6 复盘回写(防回归,loop 的灵魂)

1. 回写 `AUDIT.md`:状态改 `已修(V2.1.x)`,补一句**根因**。
2. 问自己:**这个问题类怎么让它再也不会发生?** 落到三处之一:
   - `_本地工具/一键自检.ps1` 加机器检查项(C1~C5 就是这么来的);
   - 页面 `SiteSelfTest.register(...)` 加专项检查;
   - `_本地工具/校验*.js` 数值单测。
   落不下的,在台账"备注"写明原因。
3. 若本轮修复引入了新的维护约定,同步 `CONTRIBUTING.md`。

## S7 提交

1. 单条 commit,message 对齐历史风格:`V2.1.x: 主题词+要点摘要`(参考 `git log --oneline`)。
2. 是否推送 GitHub 由用户确认(推送通道:`一键部署到GitHub.bat` 或 `git push`)。
3. 推送后瞄一眼 GitHub Actions 的 self-check 工作流是否绿。
