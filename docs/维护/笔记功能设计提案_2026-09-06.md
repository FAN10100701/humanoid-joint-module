# 学习笔记功能 · 可行性验证与设计提案(2026-09-06)

> 回应需求:①第六部分·学习工具(提案撰写时为第八部分,V2.1.21 编号连续化后为第六部分)加一个汇总入口的学习卡片;②每个页面左侧加一个跟目录一样的小框,管理文字/图片/链接/荧光笔划定笔记,支持相关搜索;③笔记只存每个使用者本地。
> 本文档是**可行性验证结论 + 设计方案**,经当轮会话对站点架构逐项核实后撰写;实施另开会话,按期推进。

## 一、结论:可行,且与现有架构高度契合

- 全站 98 页只引一个 `site.js`,导航/打卡/自测/搜索/页脚全部由它运行时注入 —— **笔记面板可走同一条注入通道,零页面改动**(不用改 98 个 HTML)。
- 站内已有三个 localStorage 先例(`humanoid-site-progress-v1` 打卡、`humanoid-site-activity-v1` 活动、`humanoid-srs-v1` 间隔复习),"纯本地存储"是既定模式,不引入任何后端,不破坏"纯静态 + 离线可用"底线。
- ES5、双主题、登记管线(sitemap/搜索索引/学习地图/首页卡片)全部有现成机制可复用。
- **工作量评估:中等**(核心 `notes.js` 约 600~900 行 ES5 + site.js 一个加载口 + 一个新汇总页走登记清单),分三期落地(见 §6)。

## 三、存储设计(单源草案)

```
humanoid-notes-v1 = {
  version: 1,
  pages: {
    "06-19": {                       // 键 = window.PAGE.pageId(站点单源)
      items: [
        { id:"n172...", type:"text",  text:"...", ts:1725... },
        { id:"n172...", type:"link",  text:"题注", url:"../02_硬件基础/07_xxx.html", ts:... },
        { id:"n172...", type:"image", text:"题注", url:"../_assets/....png", ts:... },
        { id:"n172...", type:"hl",    text:"被划原文(≤200字)", quote:"锚点引文", occ:2, color:"y", ts:... }
      ]
    }
  }
}
```

- 写入统一 `try/catch`,配额溢出(QotaExceeded)时提示"导出备份并清理失效划线"。
- 读写只经由 notes.js 一个模块(数据单源纪律,同 `Site.toggleDone` 之于打卡)。
- 无 pageId 的页(index/3D 主可视化页)不注入入口,与打卡口径一致。

## 四、关键风险与对策

| 风险 | 对策 |
|---|---|
| site.js 是全站核心,改坏影响 98 页 | 只加一个"有 notes.js 才挂入口"的加载口(~10 行);改动过 `js语法检查.ps1` + 浏览器浅深双主题目检 + 全站自检 |
| 荧光笔破坏页面结构/样式 | 只包纯文本节点;排除 svg/pre/code/h2 编号;`my-hl` 三色 class 在 site.css 配双主题变量;打印样式隐藏操作钮保留划线 |
| ES5 底线 | 不用 optional chaining/箭头函数/模板串;对照 srs.js 风格写 |
| localStorage 被"清除站点数据"误删 | 面板与汇总页常驻"导出 JSON / 导入"按钮(顺带解决换设备迁移) |
| 隐私红线 | 笔记不出网:无任何 fetch/上报;汇总页文案明示"仅存本机" |
| 自检项 | 新页登记齐全(漏登记会报 not in index);notes.js 进 PRECACHE(手动三件之一,漏了离线页会破) |

## 五、拓展功能清单(按价值排序)

1. **知识树视图(汇总页核心卖点)**:`SITE_SECTIONS`(树干)× `path-data.js`(学习路径)× 打卡进度 × 笔记密度,渲染成"我的知识树" —— 枝干=板块,叶=页,叶色=打卡状态,叶上笔记数=你下过功夫的地方。这就是"构建自己知识树"的站内化:结构用站的,血肉用你的。
2. **间隔复习联动**:荧光笔划线 + 文字笔记按 srs.js 的间隔算法生成"今日复习卡",复习时跳回原文划线处。
3. **错题→一键笔记**:自测/题库答错时的解析区加"记入笔记"按钮,自动带上题目链接与你的答案。
4. **导出 Markdown / Anki CSV**:划线+笔记按页面分组导出,进外部复习流。
5. **荧光笔语义色**:黄=概念、绿=例子、红=疑问;汇总页自动汇出"疑问清单"(红色划线列表),成为向老师/AI 提问的清单。
6. **康奈尔模板**:文字笔记条目可选"线索/笔记/总结"三段式。
7. **相关笔记在正文提示**:读到某页时,若有其他页笔记与本页关键词重叠,面板顶部提示"你在 06-02 关于『Park 变换』也记过一条"。
