# docs/ 文档索引

本目录集中存放「人形机器人学习站」的**维护与协作文档**（面向维护者、协作者、班级同学）。

## 约定

- `03_项目实操/08_完整学习手册_备查用.md` 是站点内容源稿，与其同名 `.html`（网页版）需同步维护（**md 为源、html 为版**）。
- 本仓库**严禁 `git add -A` / `git add .`**，只 `git add 指定文件`；隐私与个人开发目录（`_视频素材/`、`.trae/`、`.zcode/`、浏览器 profile、一次性临时文件）已在 `.gitignore` 忽略，切勿提交。
- 移动/删除文档前，请先在仓库内 grep 引用（README、CHANGELOG、index.html 等），避免引用失效。
