# 给协作者的站点维护交接说明(2026-08-17)

你好!无论你是人类协作者还是 AI 工具,在协助维护「人形机器人学习站」——一个**纯静态**中文教学网站(GitHub Pages + cyco.top 双端部署,无构建工具,无后端)——之前,请先阅读并遵守以下规范,避免破坏现有站点。

## 一、站点结构

- 每个板块一个文件夹:`00_3D解剖/`、`01_理论入门/`、`02_硬件基础/`、`03_项目实操/`、`04_升级进阶/`、`06_软件与算法/`、`07_前沿知识库/`、`08_学习工具/`
- 核心文件(全站运行依赖,原则上**禁止修改**):`_assets/site.js`(导航/主题/搜索/进度/自检判分/JSON-LD)、`_assets/site.css`、`_assets/search-index.js`(搜索索引)、`_assets/page-meta.js`(学习目标)、`index.html`(首页)、`sw.js`、`CHANGELOG.md`
- 页面模板:`_assets/页面模板.html` —— 所有新页面必须严格遵循其结构
- 文档与工具:维护/协作文档在 `docs/`(协作/评论/收录/维护,见 `docs/README.md`);运维脚本在 `_本地工具/`

## 二、页面硬性规范(新建/修改页面时)

1. **window.PAGE 配置**(位于 `<head>` 内联 script):必须包含 `pageId`(格式 `XX-YY`,如 `06-09`)、`root:".."`、`breadcrumb`、`prev`/`next`(指向**真实存在**的文件,路径从本页所在目录出发)
2. **结构**:`<link rel="stylesheet" href="../_assets/site.css">` + `page-head`(h1+sub+tags) + `key-point`(🎯 学习目标+建议用时) + `h2` 带 `h2-num` + `box box-tip/box-warn` + 至少 5-6 道 `.quiz` 自测题(button data-v 四选项 + .quiz-explain 解析) + 底部参考资料(注明「资料整理更新至 2026-08」)
3. **中文文本内禁止使用 ASCII 双引号(")包中文**,一律用「」——历史事故:ASCII 引号曾导致全站 JS 崩溃。JS 字符串/HTML 属性中必要的 ASCII 引号不受限
4. 页面级 CSS 类名一律 `my-` 前缀;UTF-8 编码
5. **内容准确性**:涉及数字/型号/版本/参数必须用 web_search 核实;不确定的标注「约/官方未公布」;不得编造
6. **pageId 编号**:02 板块的文件编号与 pageId 不同(文件 `04_..~15_..` 对应 pageId `02-01~02-12`);其他板块文件编号=pageId 序号。新增页面请先查看该文件夹最后一个 pageId 再续号

## 三、禁止事项

1. **禁止修改** `_assets/*`、`index.html`、`sw.js`、`CHANGELOG.md`(除非任务明确授权)——这些由主代理维护;你新建的页面需要登记(搜索索引/sitemap/学习地图)时,**不要自己改这些文件**,在完成报告里写明"需要登记:页面 XX-YY,路径 ...",主代理会处理
2. **禁止执行 git 命令**(add/commit/push 均由主代理负责)
3. **禁止运行** `_本地工具/一键自检.ps1` 等自检脚本(主代理会跑);但你可以用 `node --check` 验证自己写的 JS 语法
4. **禁止删除/重命名**其他页面与资源文件
5. **绝不提交**以下个人/隐私内容(已在 .gitignore,勿用 `git add -f` 强加):`_视频素材/`(含浏览器 profile 等隐私数据)、`.trae/`、`.zcode/`、一次性临时文件。新页面一律 `git add 指定文件`

## 六、已知问题与经验教训(2026-08-17,主代理实测记录)

### A. 3D 模块加载(最易踩的坑)
1. **不要无条件加载 es-module-shims**:它与浏览器原生 importmap 共存会破坏动态 import 的子路径解析(报 `Failed to resolve module specifier "three"`,特征是第一个 `import('three')` 成功、第二个 `import('three/addons/...')` 失败)。现代浏览器(Chrome89+/Edge89+/Safari16.4+)原生支持 importmap,不需要 shims;老内核才需要
2. **three.js examples/jsm 文件内部用裸说明符 `from 'three'`**:浏览器直接 import 时必须依赖 importmap 解析,否则报错。本站的本地库已改写为相对路径(`lib/addons/*.js` 中 `from 'three'` → `from '../../three.module.js'`),本地模式零依赖;**请勿覆盖/回改这些文件,动之前先沟通**
3. **file:// 协议下浏览器禁止加载本地 ES 模块**(相对路径也不行,CORS),必须走 CDN——3D 页已内置 file:// 自动 CDN
4. **iOS 上动态 import 失败的 error message 常为空**:靠文本匹配的容错逻辑会失效,要同时监听 `unhandledrejection`,并让加载器主动上报状态
5. **大文件(>1MB)在无 gzip 的托管上传输不稳**:cyco.top(EdgeOne)未开压缩时 three.module.js 1.2MB 原样传输,慢网络/代理下 fetch 易失败(小文件不受影响,症状是"页面能开、模块加载失败")。尽量走 .drc/.gz 压缩链,或提醒站长在 EdgeOne 开智能压缩
6. **CDN 回退要有状态机**:本地失败→CDN1→CDN2→CDN3→回本地自愈,防死循环(3D 页已实现:sessionStorage 标记 1→3→4→9);回退触发条件必须收窄(只匹配明确的模块加载错误),否则无关报错也会误切 CDN

### B. Windows / PowerShell 环境
7. **PowerShell 5.1 把无 BOM 的 UTF-8 脚本按 GBK 读取**:`.ps1`/`.bat` 文件里**禁止出现中文**(注释和字符串都不行)——中文会被读成乱码,轻则功能失效,重则语法错误闪退(曾导致部署 bat 闪退、自检脚本路径损坏)。中文字面量用正则或从文件读取绕开
8. **PS 5.1 不支持 `&&`**;git 把进度信息写 stderr,PowerShell 会显示成红色错误(exit code 1)但实际可能成功——以 `git log`/`git status` 为准

### C. 协作流程
9. **`git add -A` 会把协作者进行中的半成品一起提交**(多次发生:把对方未完成的新页面、未同步的版本号卷进自己的提交)。提交前务必 `git add` 指定文件
10. **编辑时提示 "file changed since it was read" = 协作者正在改该文件**:重读后再编辑,不要强行覆盖
11. **版本单源**:改版本必须四处同步——`_assets/site.js`(S.VERSION)、`index.html`(当前版本行+版本历史+页脚)、`CHANGELOG.md`(顶部条目)、`sw.js`(缓存名)。漏一处自检就报 FAIL
12. **新页面落地要广播 + 登记五件套**:search-index.js / page-meta.js / sitemap.xml / 首页 SITE_SECTIONS / 学习地图(节点+计数),否则自检报 "not in index"
13. 交接说明文档:本文件(`docs/协作/给协作者的交接说明.md`),改动前先读

### D. 自检与部署
14. **自检脚本的已知盲区已修**:importmap 标签(JSON 非 JS)排除、baidu_verify 文件排除、quiz/glossary 双文件同步检查、pageId↔page-meta↔SITE_SECTIONS 一致性检查。一切以 `_本地工具/一键自检.ps1` 输出为准
15. **cyco.top(EdgeOne)与 GitHub Pages 部署可能不同步**(曾落后 2 个版本):验证线上版本要直接 fetch 页面内容查版本号,不要假设
16. **百度站点验证**:验证文件必须放仓库根目录(如 `baidu_verify_codeva-xxx.html`),robots.txt 允许抓取;HTML 标签验证的 content 值为 `codeva-xxx`
17. **主题 FOUC(首帧闪烁)**:`site.css` 基础样式是深色,浅色靠 `body[data-theme="light"]` 覆盖,而主题由 body 尾部的 JS 应用——所以任何页面首帧都会闪一下深色。已修复:浅色选择器批量改为 `body:not([data-theme]),body[data-theme="light"]`。**以后新增浅色样式必须写成双选择器**(无属性时也生效),否则又会出现"打开页面瞬间夜间模式"
18. **3D 模型缓存独立**:`00_3D解剖/sw.js` 中模型(.drc/.gz/.STL/.urdf)存 `MODELS_CACHE`(独立名),**bump SW_VERSION 不再清空模型缓存**(否则每次代码升级用户都要重下 16-18MB 模型,加载"变慢"的元凶之一)。模型文件本身更新时才手动 bump MODELS_CACHE 名
19. **3D 加载统一规范(重要)**:three.js 动态加载用「直接 URL 多源」方案(本地 → npmmirror → jsdelivr → fastly)+ 超时(防网络黑洞挂起)+ 状态机(防死循环);**不要用裸说明符 `import('three')`**(依赖 importmap,无原生 importmap 的老内核必挂);`00_3D解剖/lib/addons/*.js` 已改写为相对导入,勿覆盖。D 系列页(`电机编码器与灵巧手3D拆解.html`)已按此规范(多 CDN + 15s 超时),且于 V1.9.4 **恢复上线**(pageId 00-04,磁场物理错误已修:定子磁场与转子机械角同步,不再 7 倍速;新增失步演示)——不要再标注为隐藏页

## 补充纪律(2026-08-17 协作对齐)
- **sw 版本纪律**:页面走 stale-while-revalidate,老用户第二次访问才见新内容——凡改动已缓存页面(index.html/PRECACHE 清单内文件)或大量页面内容,必须把根 `sw.js` 的 `CACHE` 名与 `S.VERSION` 同步 +1(如 v1.8.0→v1.9.0),并同步 CHANGELOG/首页版本历史。3D 目录页面改动则 bump `00_3D解剖/sw.js` 的 `SW_VERSION`。
- **JS 字符串内禁用半角双引号嵌套**:中文语境一律用「」,如 `q:"声音的「节奏」"`——嵌套 `"` 会导致语法错误(自检第一项会捕获,但请在写时就避免)。
- **新页登记五件套**:page-meta.js / search-index.js / sitemap.xml / 学习地图 PAGES / index.html(SECTIONS ids + 卡片 + 翻页链前后页 next/prev)。跑 `_本地工具\一键自检.ps1` 全绿即登记完整。
- **新页面尽早广播**:新建页面文件落地后立即告知协作方(哪怕正文未完),避免索引/翻页链出现断链窗口。
