# 全站 SVG 图解风格规范(V1.0 · 2026-09-19)

> 适用:全站所有手写内联 `<svg>` 图解(流程图/架构图/时序图/剖面示意/框图)。
> 配套执行:`.agents/skills/svg-diagram-check/`(静态审计脚本 + 双主题截图流程)。
> 现状基线:39 个含 SVG 页面,**0 错误 0 疑点**(2026-09-19 全站审计)。
> 本规范把"已经做对的"固化下来,新图照此画,改图照此查。

## 一、双主题底线(最高优先级)

1. **禁止硬编码浅色 hex 当文字色**(如 `#c9d1d9`/`#94a3b8` 直接当 fill)——浅色主题下即"悬空浅色字"。文字/标注一律:
   - 用 `#64748b`(钦定中性灰,深浅主题均 ≥4.4:1)或
   - 双主题类对:`html:not([data-theme-early="dark"])` 覆写
2. 深底图卡(自绘深色 rect 铺满 ≥70%×60%)内允许浅字——审计脚本自动识别,勿"为清零改色"。
3. 每张新图/改图必须**浅色 + 深色双主题截图目检**,缺一不可。

## 二、语义色板(全站统一,同图内不混用)

| 语义 | 深色主题 | 浅色主题 | 用途 |
|---|---|---|---|
| 主流程 / 信号 | `#58a6ff` 系(蓝) | `#2563eb` 系 | 箭头链路、主线路、强调框 |
| 警示 / 强调 | `#f0a437`(批注橙) | `#b45309` | 需要注意的分支、关键参数 |
| 成功 / 正常 | `#3fb950`(绿) | `#15803d` | 正常态、通路、通过 |
| 错误 / 禁止 | `#f85149`(红) | `#dc2626` | 故障、断路、禁止路径 |
| 注释 / 标注 | `#64748b`(钦定灰) | `#64748b` | 图例、轴标、辅助说明 |

- 红/绿不得并排做主色块(色弱不友好);对比反馈用"对 ✓/错 ✗"图形冗余。
- 蓝紫渐变大面积填充禁用(玻璃感属于页面层,不属于图解层)。

## 三、几何与线条

1. **线宽**:主干 2px,次级 1.2~1.5px,标注引线 1px;同图内同类线宽一致。
2. **圆角**:流程盒 `rx="8"`;小标签 `rx="4"`;全站统一,不混用直角/大圆角。
3. **间距**:任意两元素间距 ≥ 字号;盒内文字距边框 ≥ 6px。
4. **对齐**:同层节点水平/垂直居中对齐(肉眼检查 + 盒坐标差 ≤2px)。
5. **画布留白**:内容距 viewBox 边缘 ≥ 12px;`text-anchor` + x 预留宽度,长文案先算后写。

## 四、箭头与连线

1. **箭头必须走 `marker`**,不许裸线收尾;marker 的 fill 用双向可读色(禁硬编码深色)。
2. 回流线/反馈线**不穿过**主链节点;绕行用折线,拐点 ≥2 处。
3. 连线不穿过文字;交叉处用"跨线弧"或错开 4px 以上。
4. 时序图生命周期线、消息箭头方向与文案一致(静态审计查不出语义错,靠截图目检)。

## 五、文字与字号

1. 基准字号:节点标题 13~14px,说明 11~12px,图内最小 **10px**(再小必被审计标 W)。
2. 中文用系统栈(继承页面);数字/代号可用等宽;**斜体禁用**(中文斜体发虚)。
3. 文字溢出三步修:缩短文案 > tspan 拆行(dy 1.4em)> 拆图;禁止缩小字号硬塞。
4. 继承字号的 text(无 font-size)静态审计估不了宽,目检时重点看。

## 六、图注与编号

1. 每图必须有图注:`<div class="my-fig-cap">图① ×××</div>`,紧跟 SVG 之后。
2. 编号用带圈数字(图①图②…),**全页连续**,与正文引用一致。
3. 图例(legend)放图内底部或图注前;图例色块必须与图中实际用色一一对应。

## 七、交互与无障碍

1. 图内可点击元素(色块朗读/跳转)沿用全站委托:属性 `data-say`(朗读)/ 外链用页面级 a 包裹。
2. 根 svg 至少一个 `role="img"` 或 `aria-label`(静态审计 W 项);纯装饰图 `aria-hidden="true"`。
3. 动图(SMIL/JS 驱动)必须在 `prefers-reduced-motion` 下可停。

## 八、发图前检查单(逐项过)

1. `node .agents/skills/svg-diagram-check/scripts/svg_audit.js <页面>` → 0E 0W
2. 浅色 + 深色双主题整页截图 + 单图放大截图,过 8 项目检清单(可读/文字/箭头/对齐/图注/语义/公式/删减)
3. 问自己:"哪条线/哪个标签可以删掉?"——删掉它
4. 批量修图(≥10 处)写摘要入 `docs/审计/`;回归跑 `板块评分.js` 对账
