## 一、百度搜索资源平台(cyco.top 国内镜像)

1. 打开 https://ziyuan.baidu.com ,用百度账号登录
2. 「用户中心 → 站点管理 → 添加网站」,填 `cyco.top`,选"站点属性:科技/教育",按提示完成**域名所有权验证**(推荐 CNAME 或 HTML 文件验证,两种都支持)
3. 验证通过后,进入「普通收录 → sitemap」,提交:`https://cyco.top/sitemap.xml`
4. 「普通收录 → 链接提交 → 手动提交」,可粘贴首页与核心页 URL(首页 / 3D 页 / 面试专题 / 机型全景 / VLA 详解 等)
5. 若有能力,再接入「快速收录」(需站点改版符合要求,可跳过)
6. 百度抓取较慢(1~4 周),提交后耐心等待;可在「抓取诊断」里用"抓取测试"验证页面可访问

## 二、Bing Webmaster Tools(GitHub Pages 域名)

1. 打开 https://www.bing.com/webmasters ,用微软账号登录
2. 添加站点,选「从 Google Search Console 导入」或「手动添加 URL」均可
3. 域名验证:推荐 DNS CNAME 验证(把给定的验证码做成 `xxx.cyco.top` 的 CNAME 记录);若 GitHub Pages 域名 `FAN10100701.github.io/humanoid-joint-module` 也想收录,再加该域名并选"HTML 文件上传"验证
4. 「Sitemaps」提交:`https://cyco.top/sitemap.xml`
5. Bing 收录快(1~7 天),且会顺带喂给 ChatGPT 搜索索引

## 三、Google Search Console(可选,大陆需代理)

1. https://search.google.com/search-console 添加 `cyco.top`
2. DNS TXT 验证或 HTML 标签验证
3. 提交 sitemap.xml;Google 收录约 1~2 周

## 四、日常维护

- 每次发布新版本:内容自动更新,sitemap 无需手动改(维护者已同步);可在 GSC/Bing 后台点"请求编入索引"
- 检查收录情况:site:cyco.top 在百度/Bing/Google 搜索
- 若发现某页不被收录:优先检查该页能否直接访问、robots.txt 是否误拦、页面标题是否重复

## 五、注意

- cyco.top 与 GitHub Pages 是**同一份内容两个入口**,sitemap 只提交 cyco.top(避免重复内容惩罚)
- 不蒜子统计为第三方免费服务,若其域名不可达,页脚显示 "--" 不影响任何功能
