1 V3 底座:四大架构创新

创新解决什么一句话原理
细粒度 MoE(256+1 专家)知识容量与算力解耦每 token 路由 8 个细分专家 + 1 共享专家;用「辅助损失免费」的均衡策略替代强惩罚,不牺牲性能换均衡
MLA 多头潜在注意力KV Cache 太贵把 KV 压缩到低维隐向量缓存,推理时长上下文显存降一个量级,效果对齐全注意力
MTP 多 token 预测训练信号密度/推理加速一次预测未来多个 token:训练时多份监督信号,推理时可配投机解码加速
FP8 混合精度训练训练成本首个在超大规模验证 FP8 训练的主流开源模型;V3 全量训练成本约 557.6 万美元(GPU 时租口径,不含研发/缓存等——第三方推算口径不同,详见 SemiAnalysis 争议)
📌 参数口径(重要):V3 = 671B 总参 / 约 37B 激活 / 61 层 / 128K 上下文。所有第三方「实际成本 ×N」的推算都只计 GPU 租金口径,与全成本口径不矛盾——面试答到这层区分即满分。

2 R1:纯强化学习「觉醒」推理

R1-Zero 证明了行业级震撼结论:不做任何监督微调,直接用可验证奖励(数学/代码对错)做纯 RL,模型自己学会「先写长思考再给答案」——中途出现顿悟时刻(aha moment):自我怀疑、回溯重验。R1 在此基础上加冷启动数据与可读性约束,推理性能对齐 OpenAI o1,论文登 Nature,并把 6 个 1.5B~70B 蒸馏小模型开源。

3 V3.1 / V3.2 / V4:三条进化线

  • V3.1(混合推理):同一模型「思考/非思考」双模式合一——简单问题直出,难题先思考;终止「一模型一模式」的分裂。
  • V3.2(DSA 稀疏注意力):「闪电索引器」只让注意力关注最相关的少量 token,长上下文推理成本大幅下降、效果对标 Dense——KL 代价换数量的典型工程胜利。
  • V4:下一代底座,官方口径以技术报告为准(第三方参数传闻一律标注「以官方为准」,本站不采信未经核实数字)。

4 本节自测

1. MLA 解决的核心问题是?
💡 MLA 把 KV 压进低维潜空间,缓存体积降一个量级,让长上下文+高并发推理在有限显存下可行。
2. R1-Zero 最震撼的结论是?
💡 长思考/自我回溯等行为是 RL 奖励压力下「自发」出现的,不是教出来的——这是 2025 年最有影响力的训练结论之一。
3. GRPO 相比 PPO 去掉了什么?
💡 同一题采样一组答案,以组均值当基线省掉整张 critic 网络——显存减半、实现简化,详见下一页对比。
4. V3.1「混合推理」指的是?
💡 一个模型两种回答模式:省钱时直出答案,难题先长思考——V3.1 合并了 R1 与 V3 两条产品线。
5. MTP(多 token 预测)的收益是?
💡 每个位置多预测几个未来 token:训练信号更密;推理时主模型+MTP 头组成投机解码组合,接受率可观。
6. 「557.6 万美元训练成本」的正确理解?
💡 面试标准答案:两个口径说的是不同的东西——论文口径是「final run 的 GPU 时租」,SemiAnalysis 等推算是「全周期投入」,都有各自假设。
7. DSA(DeepSeek 稀疏注意力)的本质?
💡 注意力计算从「看全部」变「精准看少量」,成本大降且精度对标 Dense 注意力——V3.2 的主打。
8. 机器人团队选 DeepSeek 做具身底座的主要理由?
💡 底座选型三角:能力×成本×可控性。DeepSeek 在三点上均衡,是当前具身团队热门选择之一(详见 09-04 选型页)。
📌 本节小结:V3 用 MoE+MLA+MTP+FP8 把「大知识、低推理成本」做成工程现实;R1 证明纯 RL 能长出推理;V3.1/V3.2 持续把成本与体验往深推。
